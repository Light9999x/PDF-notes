## 2. 新舊規則與規劃預設

本版明確取代 v004／v005 的「點選模式」「完整包含」「獨立移動選取把手」「上方屬性按鈕再開啟」及「彈窗新增文字」。v005 的字級、對比、觸控尺寸、資料保護與共用元件原則仍沿用；不能以舊規劃推翻這次操作要求。

以下細節為建議預設，並非使用者逐項指定：

- 保留自由選取；方框及自由圈選皆採相交選取，每次新圈選取代集合，仍以起始單頁為範圍。
- 點空白處或按 Esc 可清除已完成選取；短按未選物件不退回舊點選模式。文字工具點文字框進入編輯，是另一種操作，不受此限制。
- 螢光筆尺寸欄直接代表實際直徑，取消新筆跡的隱藏 5 倍乘數；各工具分別記住顏色／大小。舊筆跡存檔中的線寬維持原值。
- 單張圖片預設等比縮放；文字框單獨拉邊框改框寬／高及換行，保留字級。混合多選使用等比整組縮放，避免旋轉物件被非等比拉成資料格式無法表示的斜切。
- 桌面右側共用固定區域，依情境顯示物件屬性或圖片庫，避免同時開兩個側欄。手機也直接開對應面板，不新增頂部「屬性」確認步驟；窄版安排見第 6 節。
- 圖片匯入面板後先成為可重用資產，拖到頁面時才建立註記物件。行動裝置另提供點縮圖後點頁面放置，作為拖曳之外的替代方式。

## 3. 選取、直接移動、縮放、自由旋轉與刪除

### 3.1 模式與幾何

- 選取工具只保留「方框」「自由選取」，預設方框。移除 point 模式按鈕、型別／狀態分支與短手勢自動點選回退；舊偏好若含 point，讀取時轉為 box。
- 只要選取區域與物件可操作範圍相交，即納入；完整包含與反向包含也應命中。只包住中心點、只檢查頂點、只比對外接矩形，都不能代替正確的相交判定。
- 筆跡／螢光筆以線段加半徑形成的實際粗線判斷，含端點、單點筆跡及粗線擦邊；不要把整個筆跡包圍盒內的空白都算筆跡。
- 文字與圖片以旋轉後的物件框判斷；圖片透明像素暫不要求逐像素命中。框內空白屬於文字／圖片框的操作範圍。
- 建議邊界接觸也視為命中，使用一致且小的數值容差。自由選取仍依顯示的奇偶填充區判斷，處理凹形、自交及洞，不因只碰到包圍盒就誤選。
- 可同時選中重疊物件。保留已刪除排除與衝突版本保護；發現衝突物件時提示略過，不自動選一個候選版本。

### 3.2 手勢優先序

| 操作起點／情境 | 結果 |
| --- | --- |
| 已選物件／群組的旋轉控制點 | 自由旋轉，與縮放控制點分開命中，優先於移動和圈選。 |
| 已選物件的縮放控制點／邊框可操作區 | 進行縮放，優先於移動和新圈選。 |
| 已選物件的實際可操作範圍 | 直接拖移整個選取集合；不需要「移動選取」標籤或獨立按鈕。 |
| 未選物件或空白區，拖曳超過門檻 | 開始新方框／自由選取。點到未選物件不能偷偷退回點選模式。 |
| 點空白，沒有形成拖曳 | 清除選取。 |
| 已選集合包圍盒中的空隙 | 除邊框控制區外，視為可開始新圈選的空白，不讓巨大透明矩形攔截整頁。 |
| 文字工具點已有文字框 | 進入該文字框原位編輯，不建立新物件。 |

- 移除舊的 `data-move-selection` 標籤與專用移動方框，但保留可見選取輪廓及縮放控制點；使用者要求移除的是額外移動操作，不是取消選取外框。
- 桌面 hover 顯示合適移動／縮放準心；手機擴大透明命中區但不得互相重疊。點選、拖曳門檻與座標換算沿用一致 CSS px／頁面座標定義。
- 指標捕捉、pointercancel、失焦、Esc 取消進行中的操作，只回復該次預覽，不留下半套縮放結果。

### 3.3 縮放、自由旋轉與歷程

- 單選四類註記均可拖邊框調整；圖片必須支援。建議角點可等比縮放，文字邊線可改框尺寸；圖片預設鎖比例，若提供解鎖需有明確控制。
- 多選以共同外框等比縮放，保留物件間相對位置與角度，更新筆跡點座標／線寬、文字位置／框尺寸／字級及圖片尺寸。不要只改 DOM CSS transform 而未改保存資料。
- 旋轉文字的框使用正確局部座標，固定對側錨點；最小尺寸須為正數，不允許穿過錨點變成負寬高或意外鏡像。圖片像素資產本身不重採樣，每個實例可有不同大小。
- 自由轉向即任意角度旋轉，不限 90°。畫筆、螢光筆、文字與圖片都適用，單選或多選都能操作；文字仍保留獨立的水平／垂直排字設定。
- 建議單選繞物件中心，多選繞共同選取框中心；拖曳時顯示角度，右側提供角度輸入及重設。多選重設以本次操作起始姿態為基準，不能把所有物件原本不同角度全部清成 0°；基準須在 UI 說明。
- 在選取輪廓外提供清楚的旋轉控制點，可有旋轉圖示，但不恢復舊的「移動選取」標籤／額外移動方框。控制點靠近頁邊時仍需可操作，不被 paper 的裁切完全遮住。
- 多選旋轉同時變更每個物件的位置與方向，保留相對配置；不能只繞各自中心轉，造成群組位置未旋轉。計算前凍結本次中心與初始快照，避免每次 pointermove 重算中心導致漂移。
- 旋轉後繼續拖移／縮放／相交選取須命中實際形狀；圖片與文字方向一致，筆跡點與線寬不因純旋轉改形。0°／90°／180°／270° 及任意正負角度均須測試。
- 現行通用 angle 欄位不代表所有渲染路徑已支援：需逐一確認圖片、筆跡、文字的模型驗證、顯示、命中、縮放、衝突預覽及 PDF 匯出。可採共用物件變換或等價座標資料，但保存、重新開啟與同步必須重現相同位置與方向。
- 如需擴充角度語意或存檔格式，提供舊檔預設、格式／版本相容規則及雙端驗證，不能只讓新客戶端理解、舊端靜默顯示錯誤。舊操作內容與合法旋轉完整保留。
- 一次拖移／縮放／旋轉／Delete 對應一次批次提交與復原／重做。保留 expected heads、儲存交易及整批拒絕策略，不能部分提交或覆寫遠端版本。
- 畫布選取有效時按 Delete 刪除所選物件；游標在文字框、頁碼／尺寸欄、其他表單或模態中時，Delete 僅處理目前輸入，不刪註記。手機保留右側屬性的刪除動作。
- 移除選取工具列的「完整包住 · 單頁 · 已選 N 個」整段與「取消選取」按鈕；不要換句話又常駐回來。必要數量可放屬性標題或輔助技術狀態中，不占同一列。

### 3.4 不誤選 PDF 文字

- 選取、繪圖、擦除、圖片拖放等編輯手勢期間，PDF text layer 同時停用 pointer events 與 user-select，處理瀏覽器原生選取／拖曳。僅停用 pointer-events 不代表文字不能被瀏覽器框選。
- 必要時清除目前閱讀區留下的原生文字選取，但範圍限於該 PDF，不清除正在輸入的文字框或頁外表單選取。
- 閱讀模式恢復 PDF 文字選取／複製；原位文字框保持可輸入、反白、複製與貼上。禁止對整個 App 永久 `user-select:none`。
- 搜尋高光不依賴原生 `window.getSelection()`，不與圈選／文字編輯互相爭用。

## 4. 顏色、尺寸與頁碼

- 螢光筆設定提供顏色控制，建立筆跡時使用該顏色，不固定 `#efc44a`。保留半透明效果；改色後儲存、同步、衝突預覽與 PDF 匯出一致。
- 畫筆、螢光筆、橡皮擦各顯示同一種「滑條＋輸入欄＋單位」元件，雙向同步。欄位是純輸入，不出現原生上下微調按鈕。
- 尺寸採頁面單位 pt，畫布縮放只改視覺大小；橡皮擦圓形準心同步反映尺寸，畫筆／螢光筆十字準心維持。
- 建議新畫筆／螢光筆範圍 1～200pt、橡皮擦 2～200pt，可輸入小數；後續可依既有限制調整並記錄。新筆跡實際直徑等於顯示值，不再為螢光筆暗乘 5。
- 輸入過程容許短暫空值／未完成小數，Enter 或失焦才驗證並套用；非法數值顯示簡短錯誤或回到最後有效值，不能一清空就跳到最小值。滑條改值時輸入欄立即更新。
- 移除「黃色螢光筆 · 線寬為所選粗細的 5 倍」。若舊工具偏好需換算，與舊物件資料分開處理，不重算已保存的筆跡粗細。
- 頁碼欄改純文字數字輸入，搭配適當 inputmode 與整數驗證；移除欄內上下微調鈕，不是移除旁邊上一頁／下一頁導航。
- 頁碼允許一次輸入多位數，建議 Enter／失焦才跳頁；驗證 1～總頁數，不因逐字變動連續跳頁，滾輪在欄上不應意外改頁。

## 5. 文字朝向與原位編輯

### 朝向是尚未修復的核心問題

- 使用者回報現象：字底朝左、文字由上往下。正確預設：字底朝畫面下方、字形正立、行內文字由左往右，換行向下；新增框預設水平、UI 角度 0°。
- 以「中文 ABC 123，測試」在普通 PDF、空白橫／直式頁面及帶原生旋轉的 PDF 上驗收，直接檢查字底與閱讀方向。不能以 `writingMode='horizontal-tb'` 或 angle=0 的斷言代替畫面結果。
- 沿「PDF viewport／原生 Rotate → 頁面 matrix → 物件 transform → SVG／HTML／Canvas 文字」追查，檢查 CSS 繼承、旋轉套用次數、Y 軸、裁切、字形基準與父層樣式。先建立能辨認方向的重現案例，再決定修正位置。
- 新增文字時的基準應符合使用者目前看到的頁面，若採頁面本地座標需正確換算；不能以 PDF 原生旋轉為由讓新建 0° 文字仍側躺。若儲存角度與 UI 角度需轉換，定義清楚且保持往返一致，不能全域硬加 90°。
- 使用者之後明確旋轉頁面，既有註記跟隨頁面；明確選直排或文字旋轉時尊重其選擇，不每次渲染強制扶正所有文字。舊文件的合法角度不全面歸零。
- 編輯中 HTML 文字、完成後 SVG、衝突預覽及合併 PDF 匯出結果須一致。若未獲啟動指示只能完成靜態修正與測試，必須保留「實際方向待驗收」，不可再次宣稱已看見修好。

### 直接在頁面上編輯

- 文字工具點空白位置，當場顯示可輸入文字框並聚焦；移除「加入文字」Dialog。游標位置與框的位置皆使用該頁座標，捲動／縮放／旋轉後不漂移。
- 點已有文字框時命中其旋轉後範圍，編輯原物件 ID，不新增重疊文字框。重疊框建議採最上層可編輯文字；衝突文字先引導處理衝突。
- 支援游標、文字選取、換行、中文輸入法組字、貼上純文字及手機鍵盤。組字中的 Enter／失焦不可提早提交或建立第二個物件。
- 建議新框先為草稿，結束編輯時以一次文字編輯提交；Enter 換行，Ctrl+Enter 或點框外完成，Esc 取消本次未提交修改。新草稿空白即不建物件；既有內容清空應保留可復原的編輯，勿直接刪除物件。
- 點另一文字框時先完成／保護目前草稿，再開啟另一個；保存失敗或遠端版本變動保留使用者草稿並提示，不悄悄覆寫、丟字或換 ID。
- 正在編輯的頁面需保持渲染；原位編輯結束後回到註記顯示，編輯框與邊框均不能輸出進 PDF。右側屬性與原位草稿使用一致資料來源，不能互相回寫舊值。

## 6. 右側預留面板

- 此需求意指閱讀區旁預留右側面板空間。桌面維持固定欄位；無選取時可顯示提示，有選取即顯示物件屬性，切換圖片工具直接顯示圖片頁面。
- 移除上方「屬性 N」／需再按一次才打開的流程。不能因視窗小於既有 900px 就把一般電腦操作自動改回二段式。
- 面板不蓋住 PDF 可用區，符合寬度與置中依剩餘閱讀寬度計算，切換屬性／圖片內容不改占位寬度，不重設閱讀錨點。面板內部自行捲動。
- 手機窄版是建議適配：選取或切圖片工具即自動顯示右側面板；可見的側邊收合入口方便恢復閱讀，不在上方額外插入開啟步驟。空間足夠時占位，極窄時可用暫時抽屜，需明記採用行為並測試不遮住必需操作。
- 圖片面板拖出圖片時，抽屜不能以模態 inert 阻止頁面接收指標。可拖曳期間切成可操作閱讀區的版面，或透過放置模式自動收合，不能要求使用者隔著不可互動的背景拖放。
- 保留 v005 未套用屬性保護，但不要為了單純展開右側面板增加確認視窗。切換面板內容時保留合理草稿，資料版本變動沿用既有衝突檢查。

## 7. 文件專屬圖片頁面

- 工具列「插入圖片」開啟右側圖片頁面，不立即叫出系統選檔、不直接切回選取模式。頁面包含明確「選取檔案」按鈕、縮圖清單、空狀態及匯入失敗提示。
- 只顯示本文件曾匯入用於註記的圖片，不混入其他文件，也不默認抽出 PDF 基底內嵌圖片。保留 PNG／JPG 支援及既有檔案大小驗證。
- 先前已使用的圖片可從歷史 image 操作所引用資產建立清單；已刪除實例的資產仍可重用。新匯入但尚未放置的圖片也必須保存為本文件圖片庫的一部分。
- 同一圖片以內容 hash 去重儲存，拖放可建立多個獨立 object ID。每個實例的座標、尺寸與刪除互不影響，刪實例不等於刪圖片庫資產。
- 從縮圖拖到指定 PDF 頁面，顯示落點預覽，放開後以目標頁的矩陣反算位置；支援捲動、縮放、旋轉及水平展示。放到非頁面區域或取消不建立物件。
- 拖曳需要支援 Pointer Events／觸控，不僅依靠桌面 HTML drag-and-drop。提供點縮圖→點頁面放置的等效操作，允許取消。
- 放置後選取新圖片以便立即拉邊框縮放；圖片頁面可保持開啟以利重複放置。只有工具列開啟圖片庫時不能自動切換選取，完成放置後選取新物件則屬合理流程。
- 圖片庫、原始 bytes 及未放置資產須離線可用，包含於 `.pdfnote`，Google Drive 同步及合併時保留雙方新增圖片。合併 PDF 只呈現已放到頁面的實例，不輸出圖庫縮圖或未放置資產。
- 現有 assets 可保存內容，但資產來源／圖片庫會員資訊是否需要新欄位須先評估；若新增 metadata，明確更新驗證、封裝、合併、同步與舊檔預設，不只增加 UI 狀態。第一輪不新增圖片庫永久清除，以免破壞歷史引用。

## 8. 搜尋文字高光

- 搜尋後在頁面中標記實際匹配文字，並捲動到第一個／目前匹配；同頁多筆逐筆前進，而非只找到頁碼。建議顯示「目前筆數／總筆數」、前一筆／下一筆，當前結果用不同邊框或色彩強調。
- 搜尋字串與 PDF text items 需建立字元範圍映射，處理同筆字串跨 span／item、中文無空白、大小寫、空白正規化及換行。不能把 items 任意加空白後搜尋，卻無法定位實際字形。
- 優先利用文字層的範圍／字形定位能力繪製匹配區域；旋轉、縮放、CropBox、裝置像素比及頁面重新掛載後仍覆蓋對應字，不使用整頁或整行大色塊代替精確匹配。
- 結果可分行產生多塊高光，不應整個外接矩形蓋住無關文字。重新輸入／清除查詢、切文件或關閉搜尋時清除舊高光；若收合僅保留結果，需在 UI 明確區分收合與清除。
- 搜尋標記是暫時介面層，不能建立螢光筆註記、不保存、不同步、不進匯出 PDF，也不攔截編輯指標。
- 掃描影像且沒有文字層時明確回報無可搜尋文字，本版不新增 OCR。PDF 基底文字為必要範圍；搜尋使用者註記文字是另行規劃，不混稱已支援。
- 大文件逐頁讀取可顯示進度，查詢變更時取消／忽略舊結果，重用可控大小的快取。未渲染頁可存搜尋結果，捲入時再繪製高光，不為搜尋把所有頁面常駐渲染。
