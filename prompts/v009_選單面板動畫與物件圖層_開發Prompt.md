# v009：選單、面板動畫與物件圖層

整理日期：2026-09-19。需求基線：App 0.8.0；同輪第 6 項資安與部署另外實作為 0.8.1。

**本文件前五項只有規劃，尚未實作。** 使用者指定「前五項先寫 prompt，現在執行第六項」。第 6 項結果記錄於 [資安檢查](../app/docs/SECURITY-REVIEW-0081.md) 與 [手機測試](../app/docs/MOBILE-TESTING.md)，不要把部署完成誤寫成下列介面功能已完成。

## 1. 已確認的五項更動

1. 移除圖片庫中的「復原移除」按鈕及「已從圖片庫移除；頁面圖片仍保留。」等移除成功說明。
2. 所有「更多」選單以覆蓋形式優先往上展開，不占版面、不推移其他物件。
3. 物件屬性面板外側收縮按鈕下方背景應與周圍一致，不出現額外異色長條區域。
4. 可調整筆跡、螢光筆、文字與圖片之間的前後重疊關係：「往上一層」「往下一層」「移到最上層」「移到最下層」。
5. 所有可伸縮頁面／面板加入簡單滑出、滑入動畫。

## 2. 實作前要確認的現況

以下來自 0.8.0 原始碼靜態檢查，不代表瀏覽器／指定真機已驗收。執行 prompt 時再次讀取最新程式，不覆蓋後續修改。

- `app/src/components/ImageGallery.tsx`：目前以 `removed` 狀態顯示成功訊息與復原按鈕；會員操作仍有明確移除／恢復因果版本。
- `app/src/components/ui.tsx` 的 `ActionMenu` 使用原生 `details`；`app/src/style.css` 一般選單向下定位，圖片庫另外將 `.card-menu` 設為 `position:static`，並讓開啟項目跨欄，會改動排列。
- 左側面板目前以 `220px 44px minmax(0,1fr)` 配置，收合後保留 44px 控制欄。控制欄及閱讀底色需一併檢查，不能只換按鈕顏色。
- `app/src/core/render.ts` 匯出依物件 ID 排序。圖層必須一起統一頁面渲染、命中測試、預覽及匯出的排序，不能只改 DOM 或 CSS z-index。
- 文件 format 4、本機 DB 版本 6，保留因果操作與衝突。新 schema 若有需要，必須提出相容／遷移方案，不直接將舊資料全部改寫。

## 3. 圖片庫文案與操作精簡

- 移除指定成功訊息、復原按鈕及其專用狀態。移除完成後自然更新清單即可。
- 保留真正的失敗／保存錯誤提示、處理中的停用保護、必要的空狀態。
- 此需求只移除介面，不能刪掉因果 tombstone、被頁面引用的圖片 bytes、歷史版本，或讓舊存檔同步後復活已移除素材。
- 明確重新匯入同圖或既有合法恢復操作仍可依原規則恢復會員。不要恢復此成功訊息；不要因此取消其他編輯功能的復原／重做。

## 4. 共用「更多」浮動選單

- 盤點文件、資料夾、圖片庫與其他實際「更多」入口，以共用元件統一行為；開啟前後卡片尺寸、清單排列及頁面捲動位置不變。
- 預設錨定觸發鈕上緣向上覆蓋；移除圖片庫跨欄／靜態選單覆寫。
- 建議預設：上方空間不足時先限制高度及內部捲動；實在不足才安全調整位置／翻向，不能把選項放到視窗外。這是邊界處理，不改成常態往下展開。
- 避免 overflow 容器裁切，必要時用 portal 或原生 popover。位於 `dialog` 時須處理 top layer，不能簡單掛到 body 後反而被對話框遮住。
- 只開一份選單；支援外部點擊、Escape 關閉、鍵盤導覽、合理焦點回復及 ARIA。點選動作後依既有規則關閉。
- 手機橫直向、safe area、放大字體、頁面捲動時保持選單可見；觸控範圍足夠。不得為避免裁切而推移內容。

## 5. 面板收縮控制與動畫

- 維持左側面板、預設展開、外側開合按鈕，不移回面板內或上方工具列。
- 讓控制區下方與閱讀區底色連續；保留按鈕可辨識的圖示、hover、focus 與展開狀態。展開／收合、桌面／手機皆檢查。
- 盤點編輯屬性／圖片情境面板、搜尋／頁面設定、同步進階設定、其他可伸縮區塊。建立清單，標示適用動畫方式，勿遺漏同類元件。
- 建議預設動畫 150–200ms、輕量 ease-out，以 transform／opacity 為主；手機覆蓋面板沿左側滑入／滑出，桌面保留現有釋放閱讀空間行為。
- 尊重 `prefers-reduced-motion: reduce`；快速反覆切換不能卡住。關閉後不可點擊或取得焦點，焦點應回到合理位置。
- 動畫中保留文字／去背草稿、選取、頁面錨點及工具狀態；避免每一動畫影格觸發整頁 PDF 重繪與適配重算。可在結束後統一更新可用閱讀範圍。
- 不將 transient 動畫座標寫回註記。必要時延後卸載，但不能讓隱藏表單參與 Tab 順序。

## 6. 物件前後圖層

- 四個指令僅改變目前頁面 App 註記的前後順序；基底 PDF 仍在最下方，PDF 內部文字／圖形不拆成可排序註記。
- 同頁單選、多選皆可操作；多選保留選取物件彼此的相對順序。明確定義「上一層／下一層」為跨過相鄰未選物件的一步，最上／最下移到該頁邊界。
- 指令放在既有物件屬性／物件操作入口，文案精簡；已在邊界或無選取時停用不適用項目。不額外擠高工具列。
- 排序要有持久化資料模型及共同排序函式，供 SVG／Canvas 渲染、反向命中選取、縮圖／衝突預覽、合併 PDF 匯出一致使用。
- 建議舊檔無排序欄位時沿用目前 ID 排序，保持舊畫面。新建物件建議置頂，請在設計文件寫明採用預設。
- 不以修改牆鐘時間、物件 ID 或整份文件最後寫入勝出處理圖層。維持離線物件合併、不同物件新增全保留；同一排序實體並行更動須保留版本並標記衝突。
- 可以採物件排序欄位或獨立頁面排序紀錄，但需先解釋不同物件重排、同物件重排、離線新增、刪除／重排、同時解決衝突等結果。排序相同時有穩定 tie-break。
- 批次操作要原子保存並可一次復原；保存失敗不留下部分排序。保留物件位置、角度、尺寸、內容及 ID。
- `.pdfnote` 重匯入、建立副本／合併、Drive 同步都需保留排序。若升格式版號，舊客戶端必須明確拒絕未支援格式，不能默默丟失順序。

## 7. 驗收清單

| 項目 | 必要驗收 |
| --- | --- |
| 圖片庫 | 成功移除後無指定文字／按鈕；錯誤仍可見；頁面圖片仍在；重開／舊檔合併不復活 |
| 更多 | 文件／資料夾／圖片選單覆蓋向上；開關不改卡片尺寸；視窗邊緣、dialog、鍵盤／觸控可用 |
| 面板 | 開關按鈕仍外置；下方無異色條；桌機釋放空間、手機覆蓋邏輯不退化 |
| 圖層 | 四種註記混疊、四個指令、單選／多選／邊界；命中最上層；匯出與畫面一致 |
| 保存 | 重開／`.pdfnote`／雙端同步排序一致；並行版本及刪除保留；復原一次還原一批 |
| 動畫 | 所有盤點區塊正常開關；減少動態效果、快速反向切換、焦點、草稿及閱讀錨點正常 |
| 回歸 | 0° 方向、上方旋轉把手、Shift 增減選、文字編輯、手動去背、搜尋高光不退化 |

指定裝置：Windows 11 25H2／i7-11800H；Galaxy S24+／Android 16，目前沒有專用觸控筆。未實際執行的瀏覽器、真機、真實 Drive 測試必須標示「未測」，不得由單元測試推稱通過。
