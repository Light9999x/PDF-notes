# v004 檢查與待驗收紀錄

2026-09-18，App 0.4.0。規格見 [v004](../../prompts/v004_文字方向版面與多物件選取_開發Prompt.md)，實作預設見 [V004-DESIGN.md](V004-DESIGN.md)。

## 已完成的程式變更

- SVG、Canvas、命中與選取框共用文字局部矩陣，共用水平／直排排版；水平字形明確採 LTR 及同一 baseline。
- 桌面保留屬性欄占位、容器寬度縮放與錨點恢復；窄視窗提供收合面板。
- 點選、方框、自由圈選，單頁完整包含、含邊界與偶奇填充，支援四類註記及重疊物件。
- 整組平移、刪除、明確修改的共同屬性，群組 Undo/Redo，預期版本與交易保護。
- 畫筆與螢光筆同為十字準心，沿用範圍橡皮擦。

以上為程式完成狀態，不代表未執行的畫面與實機驗收已通過。

## 使用者自行啟停

專案根目錄 PowerShell：

```powershell
.\app\start-pdfnote.ps1
.\app\stop-pdfnote.ps1
```

升級操作、確認保存及關閉 App 視窗的步驟見 [使用說明](../README.md)。停止回報 4173 無監聽表示服務停止；已快取的 PWA 仍可離線顯示，另關閉視窗／分頁即可。不清除網站資料、不全面結束 Node 程序。
