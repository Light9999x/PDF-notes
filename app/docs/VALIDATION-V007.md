## 自行開啟與停止

專案根目錄 PowerShell：

```powershell
./app/start-pdfnote.ps1
./app/stop-pdfnote.ps1
```

在 `app/` 可用 `npm run preview`／`npm run stop`。先完成或取消草稿、確認已存至本機，再關閉 PWA 視窗／瀏覽器分頁並停止服務。離線頁面仍可開啟不代表服務仍在監聽；不清除網站資料、不全面結束 Node。完整操作見 [使用說明](../README.md)。
