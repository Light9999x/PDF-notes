# v008 實作與採用預設（App 0.8.0）

日期：2026-09-19。依 [v008 prompt](../../prompts/v008_選取左側面板與圖片處理_開發Prompt.md) 完成七項程式更動。以下選項是本輪採用的設計預設，不視為使用者逐項確認。畫面、真機與實際帳號狀態見 [驗證紀錄](VALIDATION-V008.md)。未啟動 App／服務。

## 七項更動與互動規則

| 需求 | 實作與採用預設 |
| --- | --- |
| 點選與 Shift | `click-selection.ts` 在 pointerup 使用 pointerdown 的命中 head、原集合與 Shift 快照，重新驗證最新物件。普通點擊單選；Shift 增減選；跨頁 Shift 以該頁新集合開始。普通空白點擊清空、Shift 空白保留。 |
| 左側面板 | 同一左側內容區顯示屬性／圖片庫，外側 44px 開合控制是內容區的兄弟元素。桌面由左到右為 220px 內容、44px 控制、閱讀區；收合內容寬度為 0。手機採非模態左覆蓋，預設展開。 |
| 等高工具列 | `EditorToolbar` 永遠渲染設定槽；設定固定高度、同列對齊，窄版局部水平捲動。閱讀／圖片工具保留空槽，不加假按鈕。搜尋、頁面設定的手動展開不受切工具影響。 |
| 圖片正立 | `uprightAt` 共用既有文字的矩陣補償；反推局部角度並補回左上角落點。新圖片預覽與落點保存使用同一函式。舊圖片、使用者角度與原圖 bytes 不改寫。 |
| 旋轉控制點 | 先計算完整頁面／物件變換後的選取框畫面包圍範圍，再將上緣中央外側 48 CSS px 的控制點反轉回頁面座標。44px 命中區；靠可見閱讀區頂邊／左右邊界時移入可達範圍。 |
| 圖片庫移除 | 每張縮圖都有可觸及的更多選單。只記錄會員移除，不建立頁面刪除操作；保留資產、原始檔、頁面實例、歷史及匯出。可立即復原或重新匯入同檔。 |
| 手動去背 | 圖片庫與單一圖片屬性皆可開啟工作區。區域遮罩／連通色選取直接處理像素；輸出同尺寸透明 PNG。庫入口新增副本，實例入口只更新該物件的 asset。 |

拖曳達 5 CSS px 才分流；未選物件起拖仍建立新方框／套索，Shift 拖曳仍取代集合。多選成員在 pointerdown 不縮成單選，因此可整組移動。無效拖曳範圍不當成點擊；pointercancel、失焦及丟失 capture 取消操作。縮放／旋轉控制點優先，命中使用實際圖層順序反向查找、筆跡線段與筆寬、旋轉物件框；群組空隙不攔截。

第一次點文字只選取，原已單選文字再短按才編輯；Shift 不開文字編輯。Enter／F2、原位文字游標及 IME、未套用屬性確認、expected head 保護沿用。圖片工具沒有待放置素材時共用點選規則，待放置時落點優先。

面板內容保持掛載並使用 hidden／inert，保留屬性暫存、捲動及手動開合。左側覆蓋量同時進入可用寬度、可視區起點、fit-page、閱讀錨點與搜尋置中；指標／圖片拖放仍透過實際紙張 bounding rect 和反矩陣換算。跨斷點保持當次開合，重新開文件預設展開。

旋轉中亦保持把手位於目前畫面框上方；沿用 pointer capture、凍結中心及起始指標角差，按下不跳角。這是對「旋轉中可跟隨手勢」建議的實作選擇；紙張 overflow 保留可見控制。左側遮擋／捲動／視窗重排後重新量測可達範圍。

## 圖片庫資料、合併與版本

文件新增 `galleryOps?: GalleryOperation[]`：

```text
{ id, hash, present, parents[], device, time }
```

每個 hash 各自形成因果圖。舊 `gallery`、歷史 image asset 及會員紀錄提供候選集合；最後以會員 head 覆蓋歷史回推：任何並行 head 為 `present:false` 即隱藏，否則顯示。不以裝置時間取勝，時間僅為紀錄。

新增／移除／恢復的 parents 來自使用者當時觀察到的 head。合併按操作 ID 聯集，ID 內容不符就拒絕。明確恢復覆蓋已見移除；若另一裝置有未見移除，仍由移除優先。舊 `.pdfnote`、舊快照、重複同步及歷史資產不能自動復活會員。

會員移除無頁面 Undo 項目；介面另提供「復原移除」的新會員操作。移除取消待放置／拖曳及尚未完成解碼的落點，既有實例不受影響。遠端移除不清除正在去背的來源，因為所有資產仍保存。未做垃圾回收，不宣稱移除釋放容量。

`validateGallery` 檢查欄位、ID、資產 MIME/hash、父節點存在與同 hash、重複紀錄及循環。封裝、複製與 Drive 快照保留會員圖；快照按 ID 排序。會員與新資產、選定實例替換沿用單一 IndexedDB 交易保存；先檢查物件 expected head，失敗不發布孤立引用。Drive 沿用先資產後不可變快照。

本機資料庫由 5 升至 **6**，不重寫舊資料、變更 origin 或更名 store。舊連線收到 versionchange 時關閉；舊版本 5 客戶端重新開啟會被版本檢查阻擋。會員操作將文件提升至 **format 4**，舊 App 的匯入／同步驗證會拒絕未知 format；新 App 可讀 1／2／3／4。分類 format 1／2 不變。所有同步端需更新至 0.8.0，不支援降版。

## 手動去背範圍

使用來源正立像素預覽，不烘入 PDF 物件角度。JPEG 依解碼器的 `imageOrientation:'from-image'` 讀取 EXIF；以解碼後寬高為準，不額外再旋轉一次。PNG 輸出保持解碼後尺寸，不裁邊、不降採樣、不填白，alpha 為原 alpha 乘遮罩。EXIF 真實相機素材的瀏覽器／SVG／匯出一致性仍待驗收。

- 方框／套索使用像素中心與奇偶掃描線填充。移除累加於目前遮罩。
- 每次「保留區域」以原圖圈內重建遮罩、圈外透明，取代前次結果；介面直接說明，可復原。不提供多區聯集的隱性操作。
- 顏色使用 RGB 三通道最大差，容差 0～255（預設 24）；預設四方向連通，透明及已移除像素不通過。全域相近色須明確勾選。改容差後復原再取樣，不偷偷重算前一次操作。
- 共享遮罩提供復原、重做、重設；套用前不寫文件。取消／Esc 丟棄草稿；瀏覽器離開時提醒未完成草稿。處理取消停止當次工作且保留先前遮罩。
- 庫入口新增副本；單實例入口保留物件 ID、位置、尺寸、角度與其他屬性，只替換 asset，檢查原 head。其他實例保留原引用。原圖及已移除素材的 bytes 仍保留。
- 保存失敗顯示錯誤並保留遮罩；來源解碼或尺寸不符時停用套用。每次開啟以該資產重做，步驟歷史只在工作區存續，PNG 本身可離線、封裝與同步。

最多 **4,194,304 像素（4 Mi pixels）**；解碼前先讀 PNG／JPEG 尺寸，解碼後再次檢查。來源匯入仍為 PNG／JPEG、30 MB。預覽縮放及捲動透過 SVG 實際畫面位置換算原像素；DPR 不進入資料座標。

CPU 遮罩使用獨立 Worker，回傳進度；Abort 終止 worker，晚到結果不修改新草稿。無 Worker 或建立失敗則使用可讓出執行緒的分批 fallback。Worker 執行錯誤保留草稿並回報，不偽裝完成。歷史最多 30 份且遮罩總量不超過 32 MiB；這不是整體 RAM 上限，來源 RGBA、畫布、Worker 副本與連通佇列另占記憶體。手機效能尚未實測。

去背不呼叫外部 API、不下載 AI 模型、不新增上傳流程或依賴；套用後如已連結 Drive，資產沿用原有同步。新增 worker 由 Vite 產生本機檔案並納入 PWA 預快取；首次快取與真離線重開仍需瀏覽器驗收。

## 原型與 API 依據

Node 單元測試以實際 RGBA 陣列驗證遮罩與 alpha，使用現有 sharp 進行 PNG 編解碼往返，pdf-lib 驗證透明圖含 PDF SMask；使用既有 PDF.js 依賴中的 Node Canvas 將不對稱「UP／三色」圖實際畫出並採樣方向。這些不是 App 實際畫面／完整瀏覽器匯出驗收。

API 依據（2026-09-19 查閱）：[MDN createImageBitmap](https://developer.mozilla.org/en-US/docs/Web/API/Window/createImageBitmap) 的來源方向選項；[MDN Canvas 像素處理](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Pixel_manipulation_with_canvas) 的 ImageData RGBA；[MDN toBlob](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob) 的 PNG 輸出。API 文件不替代目標裝置測試。

使用與啟停、升級步驟見 [使用說明](../README.md)。
