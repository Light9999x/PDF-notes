## 草稿、焦點與手勢

- 單選文字開始時使用選取 ID／head，避免重疊框座標重新命中另一個物件。游標以相同文字排版及局部座標估算 UTF-16 位置；實際 IME、字形及軟鍵盤位置仍需瀏覽器驗收。
- 完成只更新內容，一次 edit batch／復原；內容未變跳過寫入。保存沿用 expected heads，失敗仍保留可複製草稿。取消保持原選取；文字工具原本新增／編輯入口保留。
- 有側欄未套用屬性時先沿用返回套用／明確捨棄對話框；原位編輯期間只保留一份有效文字來源，不讓兩個 textarea 競爭寫回。
- 收合內容使用 hidden／inert，保留元件、輸入和捲動位置。面板內焦點移至邊緣控制；原位文字不卸載，指標按面板箭頭阻止搶焦點，blur 可辨識面板控制及明確完成／取消按鈕。
- 同文件內切工具、選取及跨 600px 斷點維持手動開合；明確圖片入口展開。再次開文件重設為展開，不持久化面板偏好。
- 手機點圖待放置暫隱內容；拖圖以透明度／pointer-events 讓位，保留 capture 來源。結束或取消恢復原開合；暫時隱藏不修改手動偏好。切工具、Esc、失焦或卸載使尚未提交的圖片解碼失效。

## 縮放與閱讀位置

- `fitZoom` 使用旋轉後頁面尺寸：整頁取寬高比例較小值，寬度模式只以寬比適配；有限正值才採用，適配不套 25% 手動下限。
- 容器尺寸已排除工具列、搜尋列、頁尾及桌面面板；手機覆蓋寬度另扣一次。內距採每側 `min(72px, 可見寬度×10%)`、`min(72px, 高度×15%)`，短窗及窄版仍留正閱讀區。使用 client 尺寸排除捲軸。
- 適合整頁維持連續頁面，依布局補首尾留白、定位作用頁中心；手機水平連續的尾端也預留面板遮擋寬度。
- 自由捲動停穩 180ms 後更新作用頁。整頁模式用閱讀軸上的頁面中心距離，避免大小混排時由較大的相鄰頁搶走目前頁而往返縮放；其他模式沿用可見面積。
- ResizeObserver 以 requestAnimationFrame 合併量測，數值未變不重設 scale。拖移／繪圖／圖片拖放／原位文字中凍結適配，手勢或輸入結束後套用待處理視圖；面板收合不提交文字。
- 手動 +/- 進 manual；位置設定新增本機 zoomMode，無文件操作／同步事件。這些是程式策略，真實捲動、焦點、軟鍵盤和混合紙張畫面尚待驗證。

## 長按拉直預設

採用 Prompt 建議值，**數值仍待實際手感驗證**：有效線段最短 20 CSS px、軌跡最大偏差 `max(3px, 長度×4%)`、路徑／弦長 ≤1.15，忽略間距不足 2px 的中間抖動樣本。端點在固定 3px 半徑內停留 1000ms 才轉直；超出重計時，非從 pointerdown 累計。

計時到時重新檢查近直線及手勢身分，不需要新的 move。每個 pointer capture 有獨立 instance，取消令代次失效；pointerup 先更新最後落點，再清 timer，只提交一次。旋轉後的畫面 CSS 座標用於門檻，保存仍是頁面座標。越界終點限制在起始頁，直線鎖定後不吸角度。色彩、透明度、實際直徑不變；既有渲染、擦除、群組復原及存檔流程保持。

## 資料夾位置與相容

- 單擊／Enter 進入，拖曳後抑制開啟。根、all、unfiled 都是檢視 ID，建立／匯入時轉成 null；普通資料夾使用其原 ID。
- 瀏覽歷程記錄 scope、query、window scroll 與祖先 ID。返回恢復前一個位置，不硬跳父層；閱讀文件返回保留原位置。搜尋比對當層資料夾與文件，all 明確跨庫。
- 改名／移動按 ID 重算路徑；刪除或歷程失效返回最近仍存在的祖先或根並提示。路徑及異常分類沿用循環保護；孤立／父層衝突資料夾列根層，異常文件列未分類／根層，衝突入口保留。
- 子資料夾存在但沒有文件時不顯示空頁；真正空資料夾提供建立／匯入方式，不套首次使用引導。
- 可拖到可見資料夾、祖先或根；手機沿用移動／改名／刪除選單。祖先超過三層折至可操作的較上層選單。保留同名、自身／後代移入、空資料夾刪除及權威存檔 guard。
- 不搬移既有資料、不改資料庫版本 5、文件 format 1／2／3、分類 format 1／2 或同步協定。導航、面板、計時及縮放不寫入文件歷史。
