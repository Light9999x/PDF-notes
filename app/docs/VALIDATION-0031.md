# 0.3.1 啟動與停止修正

日期：2026-09-18。

## 原因與處置

回報時檢查到 127.0.0.1:4173 仍有監聽服務，來自上一輪代理的背景啟動 session。在其他終端機按 Ctrl+C 不會停止該 session。已透過原 session 中斷服務，確認 4173 無監聽。PWA 本身有離線快取，因此停止伺服器後仍能顯示頁面；完整關閉仍需另外關閉分頁／視窗。

## 修正

- PowerShell 啟動器直接呼叫單一 Node 程序，避免 npm 子程序轉送中斷的不確定性。
- 新增 `stop-pdfnote.ps1`、`npm run stop`，可在另一終端機正常關閉受本專案啟動器管理的服務。
- 啟動器使用 Vite preview API、固定 127.0.0.1:4173 與 strictPort，不改 origin／base。
- 隨機本機控制連接埠及權杖只存於忽略追蹤的 `.runtime/preview.json`；不透過網站提供，沒有無授權的網頁停止介面。停止驗證本專案身分、要求正常退出，並確認 4173 無監聽。
- Ctrl+C／stdin 結束／停止要求均關閉 Vite 和控制服務，移除自己的紀錄；不依 PID 強制關閉其他程序。未受管理的監聽服務會提示使用原啟動工具。
- 文件補上根目錄及 app/ 的快速指令、關閉視窗與停止服務的區別。

## 驗證

在使用者追加「以後不需要幫我執行 app」之前，已完成 `npm run test:server`，5 項通過：

1. 管線終端機輸入 Ctrl+C 字元，實際 HTTP 監聽關閉，紀錄清除。
2. 從其他工作目錄經 Windows PowerShell 啟動／停止腳本，重複停止成功。
3. 關閉啟動終端機 stdin，服務退出。
4. 未帶權杖的控制請求拒絕，重複啟動不影響既有服務及紀錄。
5. 4173 被其他測試服務占用時，停止指令只提示，該服務保持正常。

這是程序／本機 HTTP 整合驗證，不宣稱涵蓋所有 Windows 終端機宿主的實體 Ctrl+C 事件。獨立停止指令是不中斷原終端機也能使用的途徑。

收到後續偏好後不再啟動 App 或伺服器；將偏好存入根 AGENTS.md。只執行不啟動服務的靜態检查、單元測試與建置。未重跑瀏覽器 E2E；此修正不更動文件內容、編輯器、同步協定或資料庫版本。上一版 44 項單元、16 項瀏覽器驗證見 [v003 紀錄](VALIDATION-V003.md)。
