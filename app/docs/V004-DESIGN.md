# v004 設計與相容策略

App 0.4.0，2026-09-18。依 [v004 prompt](../../prompts/v004_文字方向版面與多物件選取_開發Prompt.md) 延續既有資料、閱讀與同步架構。

## 採用的規劃預設

採用單頁、完整包含且含邊界、每次圈選取代集合。方框與套索支援四類可編輯註記，不選 PDF 基底文字與圖片。多選支援平移、刪除、共同屬性及整批復原／重做；不新增永久群組、跨頁多選、整組縮放或整組旋轉。這些是依 prompt 採用的實作預設，不另記為使用者逐項確認。

桌面大於 900 CSS px 時，閱讀區與 264 px 屬性欄採兩欄配置。窄視窗改成按鈕控制的浮動面板。未增加側欄拖拉調寬。

## 文字方向

追查 `pageMatrix`、PDF.js viewport、CropBox、SVG 與 Canvas 後，保留既有頁面本地座標：原始未旋轉 CropBox 的左上角為原點，X 向右、Y 向下。`pageMatrix` 將本地座標轉為 PDF.js 畫面座標；原生 PDF 旋轉與 App 頁面旋轉只套於此層。沒有寫死的正負 90° 修正。

`annotationMatrix` 統一物件平移與文字框中心旋轉，正角度順時針。SVG 註記、選取外框、命中反矩陣與 Canvas 匯出皆共用它；衝突預覽透過 Canvas `paint` 同樣使用此定義。匯出覆蓋圖層畫在未旋轉 CropBox，保留原 PDF 的旋轉屬性。

`text.ts` 共用水平換行與直排字格座標；水平由左至右，直排逐字向下再向左換欄。SVG 明確指定水平字形渲染、LTR、alphabetic baseline，Canvas 明確指定 left/LTR/alphabetic。直排由字格位置排列，不把整段水平文字旋轉 90°。角度歸零不改 writingMode。

靜態追查未證明某個頁面矩陣存在固定角度錯誤；本輪統一了渲染與互動定義並明確限定文字方向。沒有啟動 App，因此不宣稱已重現或以實際瀏覽器畫面確認先前方向問題的根因。中英數字形與真實輸出仍須依驗收清單核對。

## 完整包含幾何

`selection.ts` 使用頁面本地座標。套索先將交叉與重疊邊切成段，再以模二計數消去重走的邊，配合 SVG `fillRule="evenodd"`。判定包括邊界；有面積的自交圖形不因總有向面積為零而被誤判為退化。

- 筆跡檢查每段中心線在區域內，並要求整段距區域邊界至少半個筆寬，包含圓形端點及單點筆跡。
- 文字使用旋轉後的四邊框；圖片目前沿用無獨立角度的矩形。各邊按區域邊界交點切段，檢查區間中點，避免頂點在內但邊穿過凹陷。也檢查框內是否存在洞的邊界。
- 每頁選取所有符合物件，不只最上層。刪除版本不選；有未解決並行版本時不選，任何候選被完整包住即提示略過。

套索最小取樣間距為 2 CSS px，超過 512 點時均勻減半保留最後一點，畫面預覽與命中使用同一條簡化軌跡。交叉切段為平方階複雜度，極端自交套索與大量物件效能仍待真機驗證。

## 手勢、狀態與保存

5 CSS px 為拖曳門檻，沒有有效區域時退回起點的點選。跨頁拖曳的座標限制在起始頁面範圍，不選其他頁。點選模式保留直接拖移；區域模式將畫範圍與明確的「移動選取」把手分開。Esc、失焦、指標取消、切工具／選取模式會取消未完成預覽並恢復先前仍有效的 ID 集合，不寫操作紀錄。

選取以 ID 集合存在 Editor 狀態，切文件由文件 ID 的 React key 重新建立。選取頁與手勢頁保持渲染，遠頁仍保留尺寸占位。收到同步或刪除更新會重算有效選取；移動中的任一預期版本變動即取消移動。屬性面板以 ID 與 head ID 組成 key，版本更新重置尚未套用的輸入，避免舊輸入套到新版本。

共同屬性只產生使用者明確修改的 patch。混合值顯示「多個值」，不複製第一個物件的值；全是筆跡時提供粗細，全是文字時提供字級、角度及排字方向，含圖片時不提供共同顏色。單選沿用完整屬性。

每個批次附帶所有物件的 expected heads；`editBatch` 先檢查整組再建立新操作，IndexedDB 寫入交易內再次檢查 durable heads。任一版本不符即拒絕整批，避免選取後發生的遠端修改被覆蓋。批次沿用既有 History 群組與單次 Undo/Redo，刪除仍是各物件獨立 tombstone，移動保留相對位置。選取框、把手、圈選軌跡與草稿不進文件、同步或 PDF。

## 版面與準心

桌面屬性欄永遠保留位置，三種選取狀態不增減欄寬。閱讀容器 `min-width:0` 並獨立捲動；符合寬度使用容器 clientWidth 扣除左右 padding。ResizeObserver 重新計算容器可用空間並恢復頁內閱讀錨點，手動縮放退出符合寬度模式。關閉瀏覽器原生 overflow anchoring，避免與程式錨點競爭。

畫筆與螢光筆皆為 crosshair，橡皮擦仍是依本地直徑、縮放顯示的圓圈。閱讀模式仍容許瀏覽器捲動與基底文字選取；編輯模式用 Pointer Events 與 pointer capture。

## 格式與發布

沿用 IndexedDB v4、`.pdfnote` format 1／2、既有 Drive appDataFolder 同步。不修改舊操作 ID 或 payload；缺少 writingMode／angle 時只於讀取解釋為水平／0°。既有非零角度完整保留，不做資料遷移或批次角度歸零。0.3 客戶端可讀既有格式；建議兩端升級以使用相同新互動行為。

App、README 與發布 ZIP 更新至 0.4.0。ZIP 加入根目錄協作偏好文件以維持 v004 prompt 的相對連結；不改動啟停管理程式、離線快取策略、使用者文件或 Google 資料。發布包為靜態 PWA，不包含 Node 啟動腳本，快速啟停指令用於原始碼專案。
