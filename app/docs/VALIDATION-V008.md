## 自行開啟與停止

專案根目錄 PowerShell：

```powershell
./app/start-pdfnote.ps1
./app/stop-pdfnote.ps1
```

在 `app/` 可用 `npm run preview`／`npm run stop`。先完成或取消文字、屬性及去背草稿，確認已存至本機，關閉 App 視窗／分頁，再停止服務。離線 PWA 仍可開啟不代表服務仍監聽；不清除網站資料，不全面結束 Node。升級相容性及完整操作見 [使用說明](../README.md)。
