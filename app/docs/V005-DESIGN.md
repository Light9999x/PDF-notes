# v005 跨裝置介面設計

App 0.5.0，2026-09-18。依 [v005 規劃](../../prompts/v005_跨裝置介面檢查與設計系統改善_開發Prompt.md)，使用專案 frontend-design、responsive-layout、design-system-architect 三個指定技能，並依 React／表單／元件整理技能實作。沒有新增 UI 套件、外部字型或收費服務。

## 採用預設與責任分界

保留米白、深綠、Lucide 圖示與本機字型。760px 控制主導覽／衝突清單，900px 控制屬性欄／抽屜；1150px 僅精簡工具文字與設定欄數，420px 處理窄表單，500px 高度處理橫向與短視窗。不同斷點服務不同內容，不合併為單一手機斷點。

桌面屬性欄維持 264px，不依選取數量改寬度。卡片以至少 240px 為桌面目標、200px 為手機目標，不足即單欄；一般內容 14–16px、次要資訊至少 12px，字級以 rem 表示。常用 HTML 控件高度至少 44px，圖示按鈕寬度亦至少 44px；選取的旋轉／移動把手擴大透明命中區，幾何座標與匯出不變。

主控制區最多占動態視窗高度 46%，短視窗為 50%，自身可捲動，讓使用者仍有 PDF 閱讀空間。這些是本輪採用的設計預設，實際尺寸、文字放大與鍵盤體驗仍待畫面驗收。

## 對話框與焦點

使用瀏覽器原生 `dialog.showModal()` 提供 top layer、背景 inert 及原生模態焦點圈限，不新增第三方 focus-trap。初始焦點放在有標題關聯的 heading，避免手機一開表單就自動彈鍵盤；使用者點欄位或 Tab 後輸入。關閉時只將焦點歸還仍存在且可見的入口。

桌面屬性元件仍是同一個 dialog DOM，透過 `show()` 以非模態側欄方式顯示，不限制背景操作、不搶焦點。窄版關閉僅呼叫 close()，不卸載 PropertiesPanel；切 900/901px 時關閉模態狀態，保持同一份暫存，縮窄後可再按屬性開啟。若原焦點因側欄收合而隱藏，移回屬性入口。

一般對話框可用明確關閉／取消／Esc，不把點遮罩當成放棄表單。保存中停用關閉；救援 alertdialog 完全不提供 Esc／遮罩／關閉入口，保留重試與救援存檔。通知在模態開啟時移入其內容區，讓錯誤不被原生 top layer 遮住；長通知自身可捲動。忙碌條移至下方，避開返回及表單標題；減少動態偏好下保留文字而停用旋轉動畫。

`editorKeyAction` 明確先排除模態與輸入欄位，焦點在按鈕／連結／選單時也不讓 Delete、Ctrl+Z 穿透成背景文件操作。搜尋框自行處理 Esc 並回到搜尋入口。桌面側欄沒有鍵盤焦點圈限。

## 屬性暫存與版本保護

屬性仍需明確按套用才保存。新增 dirty 顯示、收合保留，以及離開／選取變更前的確認；不因外觀重構改成自動儲存。畫布上的新選取／移動若遇到未套用屬性，先讓使用者處理暫存，捨棄後須重新發起指標操作，不重播已結束的 pointer event。

保存成功沿用 ID/head key 重置面板；收到遠端新版本也重置失效暫存並顯示提示。批次操作仍使用 expected heads 與既有交易保護。匯出選單提醒未套用暫存只留在本機 UI，不包含於輸出。

## 有限共用元件與維護

- `ui.tsx`：Button／IconButton 用於工具、動作、模態與衝突；Dialog／Drawer 用於上述實際表單；Field 統一標籤、說明、錯誤關聯；StatusBadge 表示同步／預覽／暫存；EmptyState 用於文件庫；ActionMenu 用於文件及資料夾；Notification 處理模態內外提示。
- `EditorToolbar.tsx` 分離讀寫控制列，Editor 保持座標、手勢、歷程與保存；`LibraryActions.tsx` 專門維持文件庫／回收區入口。
- `core/dialog.ts` 是原生視窗生命週期與關閉政策的薄層，`core/ui-policy.ts` 處理快捷鍵與設定適用性，均可不啟動服務測試。
- `style.css` 依 tokens、文件庫、設定／衝突、閱讀區、視窗、通知、斷點分區。PDF.js 外部文字層樣式與 SVG 排字／矩陣沒有重新設計。
