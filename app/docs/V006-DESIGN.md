# v006 實作設計（App 0.6.0）

2026-09-19。依 v006 全文實作，重新閱讀 frontend-design、responsive-layout、design-system-architect。本文件記錄程式與靜態設計；瀏覽器畫面、觸控與實機仍待驗收。

## 操作與資料

1. 選取只有方框／自由圈選，預設方框，5 CSS px 為拖曳門檻。相交含邊界、反向包含；筆跡採線段膠囊與圓點，文字／圖片採旋轉框。圈選沿用奇偶邊界分割與重疊邊取消，支援洞、自交；單頁選取，衝突略過並提示。短按不退回點選。
2. 手勢優先為旋轉點、縮放邊框／控制點、已選實際物件移動、新區域。群組框內空隙不攔截移動。Esc／失焦／pointercancel 取消預覽；Delete 僅在非輸入／非表單情境刪除選取。所有手勢以 expected heads 原子批次保存，每次一組復原／重做，任一成員變動整批拒絕。
3. 單圖及筆跡等比縮放；單文字可獨立調整框寬／高，保留字級。群組等比更新中心距、尺寸、筆跡點／線寬及文字字級。縮放用凍結的局部座標與對側錨點，保持正尺寸、不鏡射。所有類型可自由旋轉；群組共用中心，重設回選取時的相對角度，不把每個物件角度清零。
4. 選取控制層可溢出紙張，閱讀區預留控制空間。一般控制點透明命中直徑 44 CSS px；小於 48 CSS px 的框減為右下縮放點，避免命中區互疊。頁面設定的適合寬度會扣除側欄和控制空間。
5. 畫筆、螢光筆各有顏色／直徑偏好，文字另記顏色；橡皮擦獨立大小。滑條和純文字數值欄共用提交驗證。1–200 pt、橡皮擦 2–200 pt，支援小數；空白／未完成小數在 blur／Enter 前不提交。舊偏好僅一次將螢光筆的選擇粗細換算成實際直徑；舊筆跡完全不改寫，新筆跡沒有 5 倍乘數。

## 文字方向與草稿

資料座標維持 CropBox 左上、x 向右／y 向下，物件中心正角度為順時針。新文字依實際 `pageMatrix` 的 x 軸方向補償角度，再把框左上角錨在點擊位置；包含 PDF 原生旋轉與 App 閱讀旋轉。新框在當前畫面中是水平 0°，文字「中文 ABC 123，測試」字形正立向右。**這是座標與渲染實作目標，尚未通過實際畫面驗收。**

單物件屬性角度顯示為「資料角度＋目前頁面矩陣角度」；「水平 0°」是相對目前畫面。之後旋轉整頁時既有物件跟著頁面旋轉，不重寫舊操作。SVG、Canvas 預覽、PDF 匯出與命中共用 annotationMatrix。

文字工具點空白建立原位草稿；點既有文字框編輯最上層可編輯文字的原 ID。textarea 支援 IME、Enter 換行、Ctrl／Cmd+Enter 與離開完成、Esc 取消。組字期間暫緩提交；新空草稿不建物件、既有清空保留文字物件。正在編輯頁面保持掛載，側欄不另開競爭中的文字副本。保存中停用輸入，失敗保留文字及 expected heads，顯示可複製的救援文字；不覆寫遠端版本。未保存草稿離開頁面會觸發瀏覽器離開提醒。

## 圖片與格式相容

工具列圖片只開文件圖片庫。選檔保存 bytes、hash 及文件 `gallery` 成員，尚未放置也可離線、封裝及同步；歷史 image 操作提供舊圖片來源，刪除實例不刪資產。相同 hash 去重，每次放置建立新物件 ID。圖片支援 Pointer Events 拖曳及點縮圖→點頁面，落點以目標頁矩陣反算；預覽使用圖片實際比例。無效落點、Esc、失焦與指標取消不建物件。不抽出 PDF 內嵌圖片，不混入其他文件。

文件格式擴充至 **format 3**，非文字物件明示 angle 或新圖片庫會員資訊才提升文件格式；format 1／2 可讀，舊操作不改寫，格式不會降級。gallery 驗證引用與 MIME，merge 聯集排序，封裝／Drive 快照既有 manifest 流程保留欄位及 bytes。未放置圖片不進 PDF 匯出。

IndexedDB 由 4 升至 **5**，保留所有既有 stores 和資料；版本提升使舊版以版本 4 開庫時拒絕，避免舊程式忽略新旋轉語意。仍使用同一 `pdfnote-v1` 名稱、同一網站來源；不清除資料。升級時關閉其他舊版視窗，兩端更新至 0.6.0 再同步。未新增永久圖片清除。

## 搜尋與面板

搜尋只查 PDF 底稿文字。建立 text item 的 UTF-16 位置映射，保留跨 item、大小寫、Unicode 字元及正規化空白／換行位置；不任意在每個 item 間補空白；中文行尾接中文時不合成分詞空白，英文換行正規化為空白。逐頁異步索引、48 頁索引快取，查詢改變取消舊工作。匹配結果獨立於頁面是否渲染，文字層掛載後使用 DOM Range 的字元矩形，多行／跨 item 分開繪製。當前筆滾入視野，前後筆逐筆導航，關閉搜尋清除標記。標記不使用 Selection API、不攔截指標、不寫入文件、不進匯出。沒有文字層會顯示不支援 OCR。

桌面 **>600 CSS px** 始終預留 264px 右欄，900／901 不切換模態。手機 ≤600 使用44px側邊收合入口與非模態面板；選取及開圖片直接展開。圖片拖曳時面板透明讓出畫面，仍保留 pointer capture；點選放置則收合。屬性／圖片共享位置，切換不改閱讀寬度，未套用草稿保留並沿用明確捨棄保護。軟鍵盤、125%／150% 放大及短高度仍待實際驗收。
