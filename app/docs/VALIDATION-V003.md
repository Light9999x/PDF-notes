# v003／App 0.3.0 實作與驗收紀錄

日期：2026-09-18。依 v003 更新現有 PWA，包含範圍橡皮擦、大小調整、文字方向／任意角度、文件與資料夾拖放、連續多頁及 app/ 分離。設計與採用預設見 [V003-DESIGN.md](V003-DESIGN.md)，啟動／關閉／升級見 [README](../README.md)。

## 實作結果與預設

- 橡皮擦直徑 2–200 pt、預設 24，與畫筆設定分開。擦除 pen／highlight 整筆，排除文字、圖片及底稿。圓形掃掠按實際線段／線寬命中，快速拖過、重疊、單點及端帽涵蓋；跨頁各用自己的矩陣。
- 一次放開原子提交全部刪除，一次 undo／redo；未完成的擦除在取消／失焦／切換工具時放棄。未見遠端 head 時拒絕整組操作；衝突筆跡略過提示；tombstone 保留。
- 文字預設水平／0°，可獨立直排及中心旋轉、任意角度輸入、重設、拖控制點、局部寬高調整。中文從上往下、右往左換欄；Latin／數字／標點正立一字一格，換行另起左欄，超框裁切。SVG／Canvas 共用排版、alphabetic baseline 與旋轉。
- 資料夾父層獨立因果紀錄；本機同層不重名、跨層可同名，移動選單顯示完整路徑。拖曳有瀏覽器門檻、目標高亮、非法目標回饋及取消保護；文件／資料夾保留移動選單。非空（含子層及候選）不可刪除。同步循環／父層遺失有根層回退及管理解決。
- 預設垂直、可改水平真正多頁連續展示；不改紙張與頁面旋轉。各頁独立 Canvas／文字層／座標；附近才渲染，保留尺寸佔位及正在編輯頁。捲動作用頁、搜尋／頁碼定位、作用頁插圖與本機頁內相對錨點保持。
- App 與設定、依賴、快取、文件、建置、發布及測試目錄搬入 app/，prompts 留在根層。原 0.1.0／0.2.0 发布 ZIP 保留。根 README 為入口；Google 設定、prompt 導覽和打包路徑更新。

以上擦除範圍、整組復原、直排細則、圓形控制點與本機偏好，採用 v003 的建議預設；不回溯宣稱每一細節皆為使用者逐項指定。

## 相容與資料保留

沿用 DB 名稱及 `http://127.0.0.1:4173/`，URL base `/`，不是 `/app/`；preview strictPort 不會自行跳到其他 origin。文件與 library 可讀 format 1／2，新增進階文字／父層操作才提升為 2；舊操作 ID 與 payload 不改寫。舊客戶端拒絕 format 2，雙端先更新 0.3.0。本機 DB 4 阻止舊版直接降版開啟。

原 appDataFolder、應用標識、資產 hash 與不可變快照協定不換；`.pdfnote` 仍只包含一份文件及完整資產／版本，不封裝文件庫樹。

## 未完成的實機／外部驗收與限制

- 真實 Google OAuth、帳號容量／配額及雙端端到端同步未測；模擬 API 不替代真實帳號驗收。
- Windows 11 25H2／i7-11800H 的安裝及實體滑鼠人工操作、Galaxy S24+／Android 16 安裝／手指拖曳／手勢未驗收。無觸控筆，未宣稱壓感或防掌誤觸通過。
- 仍為 PWA；未提供原生 EXE／APK、付費服務或 Word converter，也未部署外部 HTTPS 站點。
- 瀏覽器原有私人資料未被開啟比對；保留及遷移以同 origin 隔離資料庫 fixture 驗證，沒有清除真實使用者資料。
- 大量頁面需要先讀 metadata，30 頁測試不等於 10,000 頁效能保證。記憶體、長期操作圖及大圖仍需目標實機壓力測試。
- 註記文字依裝置字型；不內嵌統一 CJK 字型，也未實作專業直排標點替換。新增文字在扁平 PDF 是點陣覆蓋層，原 PDF 保持文字層。
- 建置有既存的大型 bundle 提示（PDF 引擎等），不影響本次建置及離線測試。
