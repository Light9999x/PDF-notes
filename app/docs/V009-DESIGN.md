## 浮動選單

浮層使用 fixed 坐標，以觸發按鈕及 visualViewport 的實際邊界計算，加入 safe-area 邊距。正常優先放在按鈕上方 6px，至少保留 12px 視窗邊界；選單內容過高時內部捲動。上方不到 100px（或完整短選單所需高度），且下方空間較多時翻向。捲動／resize／軟鍵盤 viewport 改變時重新定位；觸發鈕離開可見 viewport 就關閉。

支援原生 Popover API 時放入 top layer，避免卡片／面板 overflow 裁切；portal 的 DOM 宿主為最近 dialog 或 body，確保模態內選單仍屬於模態子樹。不支援 API 時使用同一宿主中的 fixed 浮層。此相容分支與真實 dialog 裁切仍需瀏覽器驗收。

一次只保留一個開啟選單，另一入口開啟時立即關閉先前選單。支援外點、Escape、上下方向鍵、Home／End；Tab 關閉並回到觸發鈕後的可聚焦控制，Shift+Tab 回到觸發鈕。ARIA 使用具名稱的控制群組及觸發鈕的 expanded／controls，保留內部原生 button 語意。指令後回復觸發焦點；由指令開啟的新對話框接續取得焦點。關閉動畫期間浮層 inert；外點或切換另一選單可立即隱藏以讓出互動。

技術依據：[MDN showPopover](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/showPopover) 說明原生 popover 進入 top layer；此 API 能力不代表本輪已完成手機／瀏覽器驗收。

## 圖層資料與同步

Annotation 增加可選 `layer:number`，必須為安全整數且絕對值不超過 1e12；使用時文件至少 format 5。不存在時視為 0，同值按既有 `id.localeCompare` 排序，因此舊檔不改寫就維持舊畫面。`compareLayers` 與 `orderedAnnotations` 為唯一繪製順序來源。App 新建註記採目前該頁所有 head 的最大 layer + 1；離線並行新增同 rank 時依 ID 穩定排序，兩者皆保留。

採用「物件欄位」模型，排序與內容共用原物件的因果操作，沒有牆鐘排序、重配 ID 或整份文件覆寫。一次圖層指令先算新順序，單步會由頂向底（向上）或底向頂（向下），讓每組選取跨過相鄰未選物件；最上／最下以穩定分組移到頁面邊界，多選相對順序保留。完全沒有變動時不寫操作，對應按鈕停用。

有效重排將該頁可編輯物件的新位置規範化為 1…N，只對 rank 不同的物件寫操作。第一次重排舊檔可能影響同頁多個物件，不是全文件遷移。保存為同一 EditRequest 批次與 IndexedDB 交易，每個受影響物件都檢查 expected head；失敗整批不保存。編輯器歷史記下全部 before／after，可一次復原／重做。其他欄位、位置、角度、ID 和資產不變。

| 並行情況 | 結果 |
| --- | --- |
| 不同物件新增 | 全保留；相同 layer 由穩定 ID 決定前後。 |
| 不同且無交集的受影響物件重排 | 操作聯集，所有修改保留；若 rank 相同，依 ID。 |
| 兩次重排影響同一物件 | 保留多個 head，標記既有物件衝突。即使兩次原本選取不同物件，規範化範圍重疊也可能衝突，不宣稱所有不同選取都能自動合併。 |
| 同物件內容編輯與重排 | 共用物件版本，所以保留衝突；不默默取其中欄位。 |
| 刪除與重排 | null 與重排版本並存；不復活或抹除任一分支。 |
| 兩端同時解決衝突 | 各自產生觀察到原 head 的新版本；合併後仍有並行 head，需再次選擇。 |
| 舊檔重匯／重複同步 | 沿用因果圖聯集與 ID 不可變檢查；排序歷史不丟失。 |

未解決衝突不被直接排序／編輯。衝突預覽以候選版本替換該物件，與該頁其他確定物件一起依共同排序畫出，並顯示候選 layer 值，方便比較遮擋；未選其他衝突的候選版本不擅自代選。

`.pdfnote`、副本與 Drive 快照原本完整保存物件 value，因此直接保留新欄位；驗證加入 layer 範圍／format 檢查，會員操作也保留既有較高 format，不降回 4。新增排序後 **format 5**，舊客戶端拒絕未知格式。IndexedDB 升至 **7**，同名 stores 不改寫資料；舊 DB 6 客戶端無法再開啟，全部同步裝置需更新至 0.9.0，不支援降版。0.8.1 的輸入驗證和容量限制保留。

## 可伸縮區塊盤點

| 區塊 | 動畫／生命週期 |
| --- | --- |
| 左側屬性／圖片共用面板 | 180ms 水平滑入／滑出與淡入淡出。桌面保持原欄寬至關閉結束才釋放；手機覆蓋面板向左滑出，外側控制跟隨移動。內容始終掛載，隱藏／inert 保護焦點及草稿。 |
| PDF 搜尋列 | SlideRegion 垂直短距離滑入／滑出；關閉後 hidden／inert，焦點回搜尋按鈕；保留明確關閉搜尋時清 query 的既有規則。 |
| 頁面設定列 | 同上；不由切工具自動開關，設定值保留，關閉按鈕本身保有焦點。 |
| 同步進階連線設定 | 原 details 改為 Disclosure，使用同一 SlideRegion；OAuth 公開 ID 輸入不因收合卸載。 |
| 支援範圍與待驗收 | Disclosure，關閉不留可聚焦內容。 |
| 文件／資料夾／圖片更多及祖先路徑 | 共用向上浮層與短距離滑動；不占布局；外點／替換選單可即刻讓出，Escape／指令正常關閉有保留期。 |
| Drawer | 共用元件目前沒有實際呼叫入口，不新增空入口。 |
| 一般對話框、路由頁、衝突候選、去背模式 | 屬模態開關或內容切換，不是可伸縮區塊；保留既有焦點與草稿流程，不延遲關閉確認流程。 |

動畫只改內容的 transform／opacity，不插值整個閱讀區寬高。適配重算發生於布局開啟／關閉完成的尺寸改變，不逐幀重建 PDF。原位文字、去背遮罩、選取和閱讀錨點不寫入暫時動畫座標。初始呈現及 prefers-reduced-motion 為 reduce 時不播放動畫；快速反轉清除舊 timer，避免舊關閉工作把已重開內容隱藏。
