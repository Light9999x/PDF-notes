# v011 設計與採用預設

版本：0.11.0。這輪聚焦工具列、共用面板、頁間距及縮放渲染。文件 format 1～6、資料庫版本 8、群組與同步衝突規則保持相容；不需要遷移資料。

## 工具列與共用面板

- `reader-layout.ts` 集中 compact 條件：寬度 ≤600px，或寬度 ≤1100px、高度 ≤500px 且主要指標為 coarse。compact 加上 landscape 決定單列。CSS 僅讀 Editor 的 data 屬性，不以 UA 判斷，也不將所有觸控筆電視為手機。
- 一般字級的設計尺寸：直向標題 56px＋工具 52px；橫向約 53px（52px 內容加邊線），安全區另計。大字體允許自然增高。這些是 CSS 設計值，實際裝置尚未量測。
- 工具保留 44px 命中範圍，可橫向捲動，切換後讓目前工具出現在工具列範圍內。取消原本固定 68px 設定槽；所有參數移入共用面板。
- 橫向保留返回、目前工具與保存異常，更多選單包含文件完整資訊／頁碼、搜尋、匯出、復原、重做。搜尋與選單覆蓋文件；關閉搜尋返回目前可見的觸發按鈕。
- 所有工具共用同一 ContextPanel 及開合狀態；手機覆蓋文件底部，不扣閱讀區高度；桌面保留 240px 左欄。預設展開，方向切換不重建屬性元件、不清除草稿。
- 手機面板高度為 min(40dvh,360px,可用高度)，橫向為 min(44dvh,220px,可用高度)。內容內捲；VisualViewport 修正鍵盤遮擋。背景、邊框與外緣 44px 按鈕一起移動，180ms 動畫遵守 reduced motion。關閉後內容 inert／hidden；Esc 與按鈕可收合並回復焦點。

## 頁間距與幾何

`--page-gap` 在 compact 為 8px，其餘 12px；垂直／水平共用。紙張採輕陰影。閱讀區外側 padding 與適合整頁所需首尾留白仍由原本 reader-fit 計算，PDF 原生白邊與註記座標不變。

雙指預覽在 scale s 時將 flex gap 設為 gap/s，另補償錨點頁之前的間隙位移，使視覺間距固定；結束時移除預覽、同步推導新頁面幾何並在 layout effect 回復錨點。手勢期間 bitmap、文字、高光、SVG 與控制框一起變換。

每份 PDF 的原始 viewport、CropBox、原生旋轉只初始化一次（最多四項幾何讀取並行）。比例或旋轉變更透過 viewport.clone 同步推導 views，避免重新進入整份文件 loading。

## 渲染生命週期

ReaderPage 保留一組已完成 bitmap＋文字層，以舊矩陣至新矩陣的轉換立即預覽。新 canvas 與文字層在尚未掛入畫面的容器完成後一起替換；文字索引與搜尋框重新依最新幾何量測，背景替換不重新定位既有搜尋結果。

每頁 LatestFrame 以 generation／AbortController 淘汰舊請求。PDF 身分、頁碼、zoom、rotation、DPR 對應畫布尺寸變動均會取消原請求；ReaderPage 在 layout 階段更新要求。每次 render 使用獨立 canvas，不重設可見 canvas 的 intrinsic 尺寸，也不呼叫可能干擾其他工作的 page.cleanup。回收 staging canvas 在 render／text promise 結束後執行。

每份 PDF 的 RenderCoordinator 同時最多兩個背景工作，排隊任務未配置 canvas。可見頁優先，其次正在編輯／搜尋／選取頁、附近頁；超量快取先淘汰遠頁，附近預載不得擠掉高優先的可見頁。已淘汰頁重新進入範圍會載入，若仍在範圍內則提供「載入此頁」，避免無限重試。

採用的像素上限：每張 canvas 8 百萬像素、單邊 8192px、DPR 最多 2；完成快取最多 12 頁或 32 百萬像素。加上兩張 staging，位圖約束上界為 48 百萬像素（RGBA 約 192MB，不含 PDF.js、GPU 複本、文字 DOM 等額外記憶體）。一般頁面按 DPR 清晰重繪；極端大頁或高比例依畫布預算調整解析度，並非用永久低解析度取代重繪。

文件初始化、首次頁面、背景更新與真正失敗分開。背景失敗保留同頁有效畫面，錯誤／重試覆蓋而不推移文件。關閉 PDF 取消排隊與運行中的任務並釋放已完成快取。
