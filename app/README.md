依 [v001 核心功能規劃與開發 Prompt](../prompts/v001_核心功能規劃與開發Prompt.md) 實作的繁體中文 PDF 閱讀與筆記 App。

[手機測試入口](https://light9999x.github.io/PDF-notes/)及[安裝步驟／待測矩陣](docs/MOBILE-TESTING.md)。[資安檢查報告](docs/SECURITY-REVIEW-0081.md)記錄已修正項目、190 項單元測試與未驗收範圍。v009 前五項介面更動只有 prompt，尚未實作。

目前交付形式是 **可安裝 PWA**（Windows Edge／Chrome、Android Chrome），不是 EXE／MSIX 或原生 APK。提供本機程式碼、正式靜態建置及可部署 ZIP。本機功能不需 Google 帳號。Google 真實帳號同步、Windows 安裝及 Galaxy S24+ 實機驗收仍待完成，**不能視為 v001 全部核心功能已驗收交付**。

## 快速開啟與停止

從專案根目錄（`PDF-workspace`）的 PowerShell 執行：

```powershell
# 開啟服務，之後自行開啟 http://127.0.0.1:4173/
.\app\start-pdfnote.ps1
```

確認「已存至本機」後關閉 App 視窗／分頁；從另一個終端機的專案根目錄執行：

```powershell
# 停止本專案的服務
.\app\stop-pdfnote.ps1
```

若終端機已在 `app/`，改用 `npm run preview` 與 `npm run stop`，或 `./start-pdfnote.ps1` 與 `./stop-pdfnote.ps1`。PowerShell 腳本依自身位置定位，亦可使用完整路徑從其他工作目錄執行。

停止指令只向本次啟動器管理的服務要求正常退出，沒有按 PID／連接埠強制關閉其他程序。看到「4173 無監聽」表示服務停止；PWA 離線快取仍讓頁面可用，頁面／視窗需另外關閉。

依使用者偏好，代理不自動啟動 App、預覽服務或瀏覽器；需要時提供上述指令。

## 開始使用

下列指令均在 `app/` 執行（從專案根目錄先 `cd app`）。需求：Node.js 22.16 或更新的相容版本。

```powershell
npm ci --cache .npm-cache
npm run build
npm run preview
```

開啟 http://127.0.0.1:4173 。可直接執行 `start-pdfnote.ps1`；第一次使用先依上述步驟安裝依賴與建置。

1. 匯入 PDF、PNG／JPG 或 `.pdfnote`。
2. 切換畫筆、螢光筆、文字、圖片工具；閱讀模式可選取 PDF 文字。
3. 「選取」可點物件單選、Shift 點擊增減選，也可方框或自由圈選；已單選文字再短按／Enter／F2 即可原位編輯，拖曳仍移動。多選可整組移動、刪除或修改共同屬性。
4. 筆記自動存到本機。工具列提供復原／重做；鍵盤支援 Ctrl+Z、Ctrl+Shift+Z、Delete、Esc。
5. 點「匯出」，選「工作存檔」取得可編輯 `.pdfnote`，或選「匯出 PDF」保留原 PDF 文字層並將筆記扁平化加入。
6. 相同 ID 的存檔再次匯入時，可取消、建立副本或合併。不用檔名判定同文件。
7. 同一物件有並行版本時，到「衝突管理」選擇物件、逐版預覽，再決定保留哪一版。

## 資料夾與空白文件

- 「新增資料夾」可在目前資料夾建立子資料夾（全部文件／未分類檢視則建立根層）；名稱可修改，不接受空白或同層重名。兩端離線建立同名資料夾會全部保留，提示改名。
- 文件選單的「移動到資料夾」可移入指定資料夾，或移至「未分類」。移動不更換文件 ID、PDF 或筆記；搜尋限目前檢視。「全部文件」可查看所有未刪除文件。
- 刪除資料夾前要先移出全部文件，包含「已刪除文件」中的文件及子資料夾。資料夾刪除不連帶刪除文件。
- 在資料夾內匯入新文件或建立副本，會自動歸入該資料夾；合併既有文件保留它原來的分類。
- 「新建空白文件」可填名稱、選直式／橫式。採用本輪建議預設：A4、白底、一頁；留空名稱會自動命名。取消不建檔，儲存成功才開啟。
- 新建文件沿用全部註記、儲存及匯出流程。文件選單的「匯出初始空白 PDF」輸出建立時的空白底稿；工具列「匯出 PDF」才包含目前筆記。
- 分類管理衝突另列在「衝突管理」，不冒充頁面筆跡。分類衝突、已刪除或尚未下載的資料夾不會阻止閱讀，文件仍在全部文件／未分類並顯示提示。
- 資料夾與歸屬參與 Drive 同步；`.pdfnote` 仍是單份文件，不含整個文件庫的分類或其他文件。

## v008 操作說明

- **點選與 Shift**：第一次點物件只選該物件；Shift 點擊加入／移除，取消最後一個即清空。點多選中的一個會改單選，拖已選物件仍移動整組。跨頁 Shift 點擊以新頁集合開始；Shift 拖曳框選沿用取代集合。Shift 點文字不開啟編輯；已單選文字再點才編輯。空白處普通點擊清空，Shift 點空白保留。
- **左側面板**：屬性與圖片庫共用左欄，右邊緣外側箭頭收合／展開；預設展開，桌面收合後釋出 220px，留下 44px 控制區。手機採左側覆蓋面板；整頁適配、搜尋置中與閱讀錨點會扣除左側遮擋。收合保留選取與未套用草稿。
- **等高工具列**：七種工具共用固定設定槽，無設定時保留空間。窄版設定可水平捲動；短視窗的整組工具區可捲動。搜尋／頁面設定由你展開時仍會占用空間。
- **圖片及旋轉**：新放置圖片以當前可見頁面正立 0° 為預設，預覽與保存共用座標補償，舊圖片角度保留。旋轉把手位於畫面中選取範圍上緣中央；靠邊時移入可觸及區域。
- **圖片庫移除**：縮圖下方「更多」→「從圖片庫移除」。已放入頁面的實例、原圖與歷史保留；可按「復原移除」或重新匯入相同檔案恢復。移除狀態會保存／封裝／同步，舊存檔合併不會自動補回縮圖；此操作不釋放原圖磁碟空間。
- **手動去背入口**：圖片庫素材「更多」→「去背副本」新增庫內副本；單選頁面圖片→「去背此圖片」只替換該實例，其他共用原圖的實例不變。
- **去背操作**：「移除區域」可累加方框／自由圈選；「保留區域」每次以原圖圈內重建遮罩，取代先前去背結果，圈外透明，可復原。按顏色移除預設只處理四方向相連區域，容差是 RGB 最大差；勾選「全部相近顏色」才處理全圖。改容差後可復原再點。
- **去背保存**：支援棋盤透明預覽、縮放／平移、復原／重做／重設、處理取消及套用。套用前只有暫存遮罩，取消不改文件；套用輸出同尺寸透明 PNG，保留原 alpha 與原始資產。保存失敗保留工作區供重試；已套用的逐步遮罩不跨次保存。頁面實例替換可用編輯器復原，庫內新副本仍保留。
- **去背範圍**：本機離線處理、不新增圖片上傳或付費服務，不做 AI 自動主體分割；若已連結 Drive，套用後的新資產沿用既有同步。上限 4,194,304 像素，不自動降採樣；遮罩歷史最多 30 份且不超過 32 MiB。手機大圖效能／品質尚未真機驗收。

## 延續的 v007 操作（已依 v008 更新）

- **單選文字**：點選或圈選只中一個文字框後，再短按框內或在畫布按 Enter／F2 開始編輯；移動達 5 CSS px 仍拖移，縮放／旋轉控制點優先。圈選結束不自動彈出鍵盤；多選不會挑其中一個編輯。完成／取消維持原選取與工具，內容未變不新增歷史。
- **側面板**：桌面與手機進文件都預設展開。側邊箭頭一次收合／展開；桌面從 264px 左欄（含外側控制）縮為 44px，手機為非模態覆蓋面板。收合保留未套用屬性、原位文字、選取與面板捲動位置。跨斷點及切工具維持當次開合；明確按圖片會展開；重新進入文件預設展開。
- **適合整頁**：在「頁面設定」與「適合寬度」並列；依目前旋轉後紙張及未遮擋閱讀區適配，可容納低於 25% 的大頁面。跳頁及面板／工具列／視窗變更會重算，手動放大／縮小退出適配模式；文字編輯及手勢中延後重排。
- **長按拉直**：畫筆／螢光筆畫出近直線，按住端點約 1 秒可拉直；繼續移動可自由調整方向、長度，放開保存一次。採用待實測預設：最短 20 CSS px、停留半徑 3px、偏差 `max(3px, 4% 線長)`、路徑比 ≤1.15；慢畫、曲線及折返不強制拉直。Esc／取消／失焦／換工具會取消未完成筆跡。
- **圖片情境**：按「插入圖片」後持續顯示為目前工具；沒有待放置圖片時可安全圈選／調整物件。放置後仍維持圖片情境並選取新圖片，左側「屬性」可切回選取工具。手機放置／拖曳暫時讓位，結束後恢復當次開合狀態。
- **資料夾直接瀏覽**：移除資料夾導覽樹。「我的文件」根目錄列出頂層資料夾與未分類文件；單擊／Enter 進入後只列直接子項目。「返回」恢復前一個瀏覽位置的搜尋及捲動，麵包屑前往祖先。搜尋同時比對此層資料夾／文件名稱；「全部文件」是明確的全庫檢視。新增／匯入預設放目前資料夾，刪除與衝突保護沿用。

設計與預設見 [V007-DESIGN.md](docs/V007-DESIGN.md)，已測證據及畫面／真機待測矩陣見 [VALIDATION-V007.md](docs/VALIDATION-V007.md)。以下舊功能說明中，面板、文字入口、圖片情境及資料夾瀏覽以本節為準。

## 既有編輯與閱讀操作

- **選取／移動**：選取預設方框，也可自由圈選；碰到物件部分就選取。直接拖已選物件移動，拖邊框／控制點縮放，拖圓形控制點旋轉。Delete 刪除；Esc 或點空白取消選取。短按未選物件會單選，Shift 點擊增減選；群組框內空隙可開始新圈選。
- **縮放與旋轉**：單圖等比、單文字改框寬高並保持字級，多選等比整組縮放。所有類型支援旋轉；單物件角度相對目前可見頁面，群組重設回起始相對方向。每次操作一組復原／重做。輸入欄中的 Delete 不刪物件；衝突版本不能直接操作。
- **左側面板**：桌面 >600 CSS px 展開時預留左欄，側邊可收合；選取更新屬性內容，圖片按鈕展開圖片庫。手機為非模態左側面板，側邊可收合／展開；圖片放置時讓出頁面。有未套用屬性時保留暫存，套用或明確捨棄後再變更選取。
- **文字**：點空白位置直接輸入，點已有文字框編輯原物件。Enter 換行，Ctrl／Cmd+Enter 或點框外完成；Esc 取消。支援中文組字；新空白草稿不保存，既有文字清空是可復原編輯。保存失敗保留草稿與救援文字，先複製／重試後再離開。
- **文字方向**：新文字按當前頁面矩陣補償原生／閱讀旋轉，目標為字底朝下、水平向右。既有文字仍隨頁面旋轉，舊角度不重設。實際字形朝向與編輯框仍待畫面驗收，不能僅以矩陣測試宣稱已實機修復。
- **尺寸與顏色**：畫筆、螢光筆與橡皮擦採滑條＋純輸入（pt），Enter／離開欄位才確認輸入。螢光筆可選顏色，數值直接代表直徑；各工具分別記憶。舊筆跡線寬不變。
- **圖片**：「插入圖片」→「選取檔案」先保存到本文件圖片庫，再拖到頁面，或點縮圖後點頁面放置。每次放置獨立，可縮放／旋轉；刪除實例仍保留圖庫。未放置資產可離線、備份及同步；不抽取 PDF 內嵌圖片。
- **頁碼**：純輸入，打完整頁碼後 Enter／離開確認；非法／超範圍恢復原值。保留獨立上一頁／下一頁。
- **搜尋**：輸入 PDF 文字後逐頁搜尋，匹配字元高光；前後筆逐筆定位，顯示目前／總數。關閉清除標記，不寫入註記或匯出。掃描頁無文字層時提示不支援 OCR。
- **閱讀／編輯隔離**：閱讀可反白複製 PDF 文字；編輯模式停用 PDF 原生反白，但原位文字框仍可選字。
- **介面**：文件庫保留匯入、新建空白、資料夾與回收區；移除重複標語／空狀態。屬性、搜尋、同步與衝突依情境顯示必要內容，保留資料風險與救援。

## v003 編輯與連續閱讀

- **橡皮擦**：直徑 2–200 pt，預設 24 pt，與畫筆粗細分開記住。按住滑鼠拖曳擦除圓圈及路徑碰到的所有整筆畫筆／螢光筆；文字、圖片及 PDF 底稿不擦除。單次拖曳是一組復原／重做。游標移動但未按下不刪除；Esc、切換工具、失焦或指標取消會放棄本次尚未完成的擦除，已完成的保存不撤回。碰到衝突筆跡會略過並提示。
- **文字**：新框相對當前可見頁面水平向右、0°。使用「選取」開啟屬性，可改成直排（上到下、右到左換欄），輸入任意角度、重設為 0°，或拖曳框上的圓形旋轉控制點。方向與旋轉互相獨立，以框中心旋轉；寬高是旋轉前的框。屬性按「套用變更」才保存。
- **混排規則**：直排中每個中文字、英文字母、數字、標點皆正立占一格，字格／行距為字級的 1.35 倍；換行另起左欄，不足高度自動換欄，超出寬度裁切。未加入直排標點替換或連字。水平排字依相同裝置字型測量換行。旋轉、裁切及排版同時用於畫面、衝突預覽和 PDF 匯出。
- **拖放**：滑鼠拖文件到資料夾／未分類；拖資料夾到可見子資料夾／麵包屑祖先／「我的文件」根目錄。採瀏覽器原生拖曳起動距離，移動滑鼠超過門檻才開始。有效目標會高亮；自己、子孫、同層重名、待處理階層會拒絕。Esc、放到空白或原位置不變更。全部文件只是檢視，不是歸屬。文件與資料夾都有「移動」選單供手機使用。
- **階層衝突**：跨裝置搬移形成循環、父層被刪除／尚未同步時，資料夾暫列根層，內容仍可開啟。在「衝突管理」可移回根層；父層有並行版本也可選擇候選。
- **連續閱讀**：預設垂直多頁，用滾輪跨頁；「展示方向」可改水平向右排列。水平模式把普通滾輪映射為水平移動，保留原生水平輸入與 Ctrl／Cmd 縮放。展示方向不改 PDF 紙張及旋轉。
- 頁碼、上一頁／下一頁及搜尋會捲到目標頁。主要可見頁是目前作用頁；圖片依實際放置頁面定位；文字點擊與筆跡屬所操作的頁面。一筆畫線不跨到另一页，間隙不建立註記。
- 每份文件在本機記住展示方向、縮放、旋轉及頁內相對位置；不進入雲端內容衝突。附近頁面才建立畫布與文字層，遠頁保留尺寸佔位，正在操作／選取的頁面會保留。

## 關閉 App 與停止本機服務

1. **先確認本機保存**：完成輸入或按下「套用變更」後，等待顯示「已存至本機」。原位文字草稿、未套用屬性及未套用去背遮罩不算已儲存；出現儲存失敗時先重試或匯出救援存檔，不直接關閉。
2. **如需另一台立即接續**：在網路與 Google 授權可用時，等待「同步完成」。離線時仍可在本機保存後關閉，之後重開 App 並重新連結 Google，再補同步。關閉後不保證背景繼續同步。
3. **關閉畫面**：Windows 已安裝的 PWA 按視窗右上角 `×` 或 `Alt+F4`；瀏覽器／內建瀏覽器版本關閉該分頁即可。Android 可離開 App，或從最近使用的應用程式將它滑除。這些動作不會刪除已存資料。
4. **停止本機伺服器**：可在啟動服務的同一個終端機按 `Ctrl+C`。若沒有停止、已回到提示字元，或服務由另一個終端機／工具啟動，在專案根目錄執行 `./app/stop-pdfnote.ps1`；若在 `app/` 則執行 `npm run stop`。等待回報「4173 無監聽」。不要只以分頁還能使用來判斷，PWA 離線快取不需要伺服器也能顯示。開發模式 `npm run dev` 的 5173 服務仍需從它原本的終端機停止，停止指令只管理正式預覽服務。
5. **下次啟動**：需要提供本機網站或取得更新時，在此專案重新執行 `npm run preview` 或 `start-pdfnote.ps1`，開啟同一網址 `http://127.0.0.1:4173`。已快取完整的正式 PWA 可離線使用；若顯示連線失敗，先重新啟動伺服器。

請勿用「清除網站資料」、刪除瀏覽器設定檔或解除安裝並清除資料作為關閉方式，這些可能刪除本機文件。0.3.1 起，透過新版啟動腳本／npm preview 啟動的本專案服務，可跨終端機停止。舊版直接 Vite 或其他工具啟動的服務没有管理紀錄，需從原工具停止；停止指令會明確提示，不會一次結束所有 Node.js 程序。

## 升級至 0.8.0

0.8.0 將同名本機資料庫升至版本 **6**，保留全部文件、資產、設定及分類，舊操作不改寫。使用圖片庫新增／移除／恢復（含去背副本）時，文件使用 **format 4** 與不可變會員紀錄；可讀 format 1／2／3，分類仍為 format 1／2。

舊版 App 不能開啟版本 6 的本機資料庫，亦會拒絕 format 4 存檔／Drive 快照，避免忽略移除紀錄；不支援降版。**所有同步裝置先更新至 0.8.0**。明確重新匯入／恢復能蓋過已看見的移除，未看見的並行移除仍優先。保留同一網址和瀏覽器設定檔，不清除網站資料。

先完成文字／屬性／去背草稿並匯出重要 `.pdfnote` 備份，關閉其他舊版分頁／PWA 視窗。於 `app/` 執行 `npm run build`，需要時自行啟動；出現更新提示後重新載入更新。面板換邊、選取與工具設定不修改既有頁面物件。

### 歷史相容界線（0.6.0／0.7.0）

先確認保存並匯出重要 `.pdfnote` 備份，關閉其他舊版分頁／PWA 視窗，在 `app/` 執行 `npm run build`。啟動服務後，看到「同步與設定」更新提示時選「重新載入更新」；必要時關閉後重開。請保持 `http://127.0.0.1:4173/`、同一瀏覽器設定檔及網站 base `/`，**不要改成 `/app/` 或清除網站資料**。連接埠被占用時服務會拒絕啟動，不改用其他連接埠。

0.6.0 將資料庫版本升至 5，保留同一資料庫全部文件、資產、分類及設定，舊操作內容不改寫。舊版版本 4 客戶端無法再開啟此資料庫，避免忽略新旋轉語意；不支援降版。format 1／2 存檔可讀；非文字物件旋轉與新增圖片庫會員採 format 3，舊版會拒絕新版存檔／同步快照。當時要求兩台裝置先更新至 0.6.0；目前以 0.8.0 為同步基線。新工具偏好一次遷移螢光筆實際直徑，不修改舊筆跡。

## 安裝與離線

- Windows：開啟本機網址，等待「同步與設定」顯示 App 已快取，再用 Edge／Chrome 的安裝功能。初次載入需啟動本機伺服器；快取完成後，本機檔案操作不依賴伺服器。
- Android：將 `dist/` 的內容部署至自己可用的 **HTTPS 靜態站點根目錄**，以 Chrome 開啟並安裝。ZIP 在 `release/`。未替使用者建立外部帳號、購買服務或發布任何站點。
- `http://電腦區網IP` 在手機通常不是安全來源，不能取代 HTTPS 安裝途徑。
- 安裝與授權完成前不要清除網站資料；正式版包含 PDF worker、CMaps、標準字型及 WASM 的離線快取。開發伺服器 `npm run dev` 不啟用 service worker。
- 清除網站資料會刪除本機文件。持久儲存由瀏覽器裁定，請定期匯出 `.pdfnote` 備份。

## Google Drive

見 [GOOGLE_DRIVE_SETUP.md](GOOGLE_DRIVE_SETUP.md)。使用 `drive.appdata`，不要求整個 Drive 的讀寫權限。App 只存取自己的隱藏資料區，原檔與筆記不經過開發者伺服器。

授權有效時，儲存後、恢復連線、回到前景，以及開啟期間定時同步。Google 網頁 token 模式的存取權杖僅保存在記憶體；到期或 App 重新啟動後必須重新連結。尚未完成免互動長期登入；關閉 App 不承諾持續背景同步。

## 驗證

```powershell
npm run check
npm test
npm run build
```

以上不啟動 App。端到端與啟停測試會啟動服務，只有明確要求時才執行；本輪兩者皆未執行。手動端到端指令：

```powershell
npm run test:e2e
```

若自動啟停預覽服務在 Windows 終端機卡住，可在一個終端機先 `npm run preview`，另一個終端機執行：

```powershell
$env:PDFNOTE_EXTERNAL_SERVER = '1'
npm run test:e2e
Remove-Item Env:PDFNOTE_EXTERNAL_SERVER
```

完成後在 `app/` 執行 `npm run stop`，或回到預覽服務終端機按 `Ctrl+C`。這只改測試如何管理服務，不改測試內容。

端到端測試使用此 Windows 已安裝的 Microsoft Edge（Playwright `channel: msedge`）。結果與限制見 [docs/VALIDATION.md](docs/VALIDATION.md)；架構與資料協定見 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

v002 新增資料設計見 [V002-DESIGN.md](docs/V002-DESIGN.md)，歷史测试見 [VALIDATION-V002.md](docs/VALIDATION-V002.md)；目前見 [VALIDATION-V008.md](docs/VALIDATION-V008.md)。執行 `node scripts/release.mjs` 產生 `release/pdfnote-0.8.0-pwa.zip`。

## 格式支援

Windows PWA 與 Android PWA 共用以下本機程式碼；Android 實機結果尚待驗證。

| 格式 | 匯入為文件 | 插入成可編輯物件 |
|---|---|---|
| PDF | 已實作；加密 PDF 明確拒絕 | 不適用 |
| `.pdfnote` | 已實作；包含資產、版本與衝突 | 不適用 |
| PNG | 已實作；內建本機轉 PDF，留存原圖 | 已實作 |
| JPG／JPEG | 已實作；內建本機轉 PDF，留存原圖 | 已實作 |
| DOC／DOCX | 依既有授權延後 | 不支援 |

不內建 Word 排版引擎：目前未找到已驗證可在 Windows／Android PWA 同時離線內建、且保有 Word 排版相容性的免費方案。LibreOffice 另裝桌面程式的方式不符合此版跨平台內建方向。圖片轉 PDF 不產生 OCR 文字層。多張圖片排序合併尚未提供（屬建議細節）。

## 已知限制

- 真實 Google OAuth 與雙端 Drive 同步仍需用戶端 ID、HTTPS 來源及使用者登入，不能以模擬 API 測試替代。
- 非原生安裝包；Android 的 HTTPS 部署及目標裝置安裝尚未完成。
- 來源檔上限 100 MB；插入圖片 30 MB；可攜存檔 150 MB；大量頁面／長期操作紀錄效能尚待實機測試。
- 筆跡可改顏色、粗細、透明度、位置、大小及刪除；尚無逐節點路徑編輯。橡皮擦只刪除整筆畫筆／螢光筆。
- 筆記文字和圖片以最高約 144 dpi 的透明覆蓋圖層加入 PDF（大頁面最長邊上限 4096 px）；原 PDF 保持向量及文字層。新增文字在分享 PDF 中不可搜尋，`.pdfnote` 仍可編輯。
- 文字使用裝置中文字型，跨平台可能有字形／換行差異。未內嵌統一 CJK 註記字型。
- 支援連續多頁閱讀、捲動、縮放及記憶位置。文字搜尋定位至頁面，不逐次高亮匹配字串。
- 畫筆保留 Pointer Events 輸入設計，但壓力粗細、防掌誤觸、觸控筆及真實手機多點手勢未驗證。
- 刪除文件為可同步 tombstone，保留可還原資料，不立即釋放原檔或雲端歷史空間。未做歷史壓縮或垃圾回收，避免長期離線裝置復活已刪除物件。
- Google 雲端 API、隱藏區與裝置本機資料均沒有額外 App 端端對端加密；不宣稱具有此保護。

所有套件使用免費開源授權，依賴版本鎖在 `package-lock.json`；見 [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md)。

## 0.3.1：啟動與停止修正

`start-pdfnote.ps1` 直接啟動單一 Node preview 程序，避免 PowerShell → npm → Vite 的多層包裝。支援 Ctrl+C、終端機輸入結束及受本機隨機權杖保護的停止要求；`stop-pdfnote.ps1`／`npm run stop` 可從另一終端機停止同一專案，重複執行安全，明確確認連接埠狀態。不更動瀏覽器儲存、離線快取、筆記或 Drive 資料。

驗證與已知界線見 [啟停修正驗證](docs/VALIDATION-0031.md)。停止服務不代表關閉離線 App 視窗；代理之後不自動執行 App。
