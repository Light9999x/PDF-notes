# PDFnote 使用與本機執行指南

**[直接開啟 App](https://light9999x.github.io/PDF-notes/)** · [第一次使用](../README.md) · [Google Drive 設定](GOOGLE_DRIVE_SETUP.md)

目前原始碼版本 **0.9.0（測試版）**，本輪尚未發布到線上測試站。一般使用者從網站開始即可，不需要安裝開發工具。本文件補充編輯、保存與故障處理；需要自行執行程式時，再看後半部的本機步驟。

## 閱讀與編輯

### 閱讀 PDF

1. 在「我的文件」開啟文件，選「閱讀」。此模式可選取、複製 PDF 原有文字。
2. 上下捲動跨頁，或輸入頁碼後按 Enter。要橫向閱讀，展開「頁面設定」，將「展示方向」改為「水平連續」。
3. 在「頁面設定」選「適合寬度」或「適合整頁」，也可自行放大、縮小或旋轉頁面。
4. 按「搜尋」輸入 PDF 文字，用「前一筆／下一筆」定位並查看高光結果。掃描圖片沒有文字層時無法搜尋；目前沒有 OCR。

### 畫筆、螢光筆與橡皮擦

1. 選「畫筆」或「螢光筆」，調整顏色與直徑。尺寸可拖滑條，或輸入數字後按 Enter。
2. 在頁面按住拖曳畫線。畫出接近直線的線條後，在端點按住約 1 秒可拉直；繼續拖曳調整方向與長度，放開定型。
3. 要刪除筆跡，選「橡皮擦」並調整大小，再按住拖曳。碰到的畫筆／螢光筆會整筆刪除，不擦掉文字、圖片或原 PDF。
4. 操作錯誤可按「復原」，需要時再按「重做」。

### 新增與編輯文字

1. 選「文字」，點頁面空白位置，直接在新增的文字框輸入。
2. Enter 換行；Ctrl+Enter 或點框外完成輸入，Esc 取消當次編輯。
3. 再次點既有文字框可編輯。使用「選取」時，先單選文字框，再短按框內或按 Enter／F2，也可進入編輯。
4. 在左側屬性調整字級、橫排／直排及角度後，按「套用變更」。面板外側箭頭可收合或展開。

### 選取、移動與調整大小

| 操作 | 方法 |
| --- | --- |
| 單選 | 切到「選取」，點一個物件。 |
| 範圍選取 | 選「方框」或「自由選取」，在空白處拖出範圍；碰到物件部分區域就會選取。 |
| 增加／減少選取（鍵盤） | 按住 Shift 點物件：未選取的加入、已選取的移除。 |
| 移動 | 直接拖曳已選取的物件；多選時整組移動。 |
| 縮放／旋轉 | 拖邊框／控制點縮放，拖圓形旋轉控制點改變角度。 |
| 刪除／取消 | 按 Delete 刪除；Esc 或普通點空白處取消選取。輸入文字時 Delete 只處理文字。 |

單獨圖片與多選群組採等比縮放；文字框調整寬高時保留字級。手機沒有實體鍵盤時，可在屬性面板按「刪除物件／刪除所選物件」。遇到物件版本衝突，先到「衝突管理」處理。

### 調整物件前後順序

單選或多選後，在左側屬性選「往上一層／往下一層／移到最上層／移到最下層」。只調整本頁註記，原 PDF 固定在底部；多選保留彼此順序。上一層／下一層會跨過相鄰未選物件；到達邊界時按鈕停用。一次操作可一次復原，重開、工作存檔和 PDF 匯出保留順序。新建物件放在目前頁面最上層。

若兩台裝置同時改到同一物件（包含排序影響的鄰近物件），仍須到衝突管理比較版本；預覽會顯示候選物件與頁面其他確定物件的疊放效果。

### 插入圖片與手動去背

1. 按「插入圖片」→「選取檔案」，匯入 PNG／JPG。素材保存在目前文件的圖片庫。
2. 拖縮圖到頁面，或點縮圖後點頁面放置。同一素材可多次放置，各圖片物件可獨立移動、縮放及旋轉。
3. 要從素材製作透明副本，選縮圖的「更多」→「去背副本」；要替換頁面上的單一圖片，單選後按「去背此圖片」。
4. 用「移除區域」圈出要刪的部分，或用「保留區域」圈出要留下的部分；也可按顏色移除。檢查透明預覽後再套用。

「保留區域」會以原圖重新建立遮罩，取代之前的去背結果；可復原。預設顏色移除只處理相連區域，勾「全部相近顏色」才處理全圖。取消不改文件；套用後保留原圖並保存透明 PNG。

目前是免費本機手動去背，沒有 AI 自動分割，上限 4,194,304 像素。「從圖片庫移除」只移除素材清單項目，已放到頁面的圖片仍保留，也不立即釋放原圖空間。移除後清單直接更新；要恢復可重新匯入相同檔案。

「更多」選單優先向上覆蓋，空間不足時可在選單內捲動；不會推移卡片。可用方向鍵／Home／End 移動焦點，Esc 關閉。左側面板、搜尋、頁面設定及同步進階設定有簡短滑入／滑出，會尊重裝置的減少動態效果設定。

## 整理文件

- 按「新增資料夾」建立資料夾，點資料夾進入；用「返回」回前一個位置，或點上方路徑前往上層。
- 在目前資料夾匯入／新建的文件會放入該處。「全部文件」可查看整個文件庫的未刪除文件。
- 文件的「更多」→「移動到資料夾」可選目的地；資料夾也有移動操作。電腦可直接拖文件或資料夾到有效目的地。
- 刪除文件後可到「已刪除文件」還原。刪除資料夾前須先移出裡面的文件及子資料夾，包含仍歸屬此處的已刪除文件。

## 保存、備份與換裝置

完成文字輸入、套用屬性／去背後，等待 **「已存至本機」**。尚未套用的草稿不算已保存；若失敗，保留畫面並重試，或先匯出救援存檔。

| 想做什麼 | 操作 |
| --- | --- |
| 保存可繼續編輯的備份 | 文件內「匯出」→「工作存檔」，下載 `.pdfnote`。 |
| 分享或列印 | 文件內「匯出」→「匯出 PDF」。有未解決衝突時，先處理衝突；工作存檔仍可保留所有版本。 |
| 取回匯入前的原檔 | 文件庫「更多」→「匯出原始檔」。空白文件則顯示「匯出初始空白 PDF」。 |
| 不用雲端換裝置 | 傳送 `.pdfnote` 到另一台裝置，再按「匯入文件」。 |
| 重新匯入相同文件 | 選「建立副本」成為獨立文件，或「合併」保留兩邊操作；相同文件由 ID 辨識，不是看檔名。 |

`.pdfnote` 包含原始檔與版本歷史，分享時會一起帶出；它不包含其他文件或整個資料夾分類。匯出 PDF 保留原 PDF 的文字層，但新增註記會合併成圖像，不具原本物件的可編輯性，新增文字也不能搜尋。

**請保留定期匯出的備份。** 清除網站資料、刪除瀏覽器設定檔可能刪除本機筆記。不同瀏覽器、裝置與網站來源各有自己的資料；`http://127.0.0.1:4173/` 和線上測試站不共用本機筆記。

## 離線、同步與更新

### 離線使用

在「同步與設定」等待「App 已快取，可離線開啟」。之後本機閱讀、編輯、匯入及匯出可離線使用。可按「保留本機資料」申請持久儲存，但是否核准由瀏覽器決定，仍需自行備份。

### Google Drive（選用）

先依 [Google Drive 設定](GOOGLE_DRIVE_SETUP.md) 建立自己的 OAuth 用戶端，再於兩台裝置連結同一帳號及同一 Google Cloud 專案。僅存取 App 專用隱藏資料區，不要求整個 Drive 的讀寫權限。

在網路與授權可用、App 開啟時會同步；要立即切換裝置，先等待「同步完成」。到期或重開 App 後需重新連結。不同物件會合併保留；同一物件的不同版本到「衝突管理」逐一查看並選擇。

### 更新 App

1. 完成正在編輯的文字、屬性及去背，等待保存完成，匯出重要 `.pdfnote` 備份。
2. 關閉其他舊版分頁／App 視窗，再連網開啟平常使用的同一網址。
3. 在「同步與設定」出現更新提示時，按「重新載入更新」。所有同步裝置都應更新。
4. 不要清除網站資料或用降版處理更新問題。0.9.0 使用資料庫版本 7，支援文件 format 1～5；新增／調整圖層使用 format 5。舊客戶端會拒絕新版資料，所有同步裝置請一併更新至 0.9.0。舊文件的原始順序與歷史保留，不支援降版。

自行在電腦執行的版本，需先更新程式碼並重新建置，步驟如下。

## 在 Windows 本機執行

只有想自行執行或開發時才需要本節。先安裝 [Node.js](https://nodejs.org/)（含 npm；此專案自動檢查使用 Node.js 24）及 [Git](https://git-scm.com/)。安裝後重新開啟 PowerShell，用 `node --version`、`npm --version`、`git --version` 確認可執行。若選擇下方的 ZIP 下載方式，可以不安裝 Git。

### 1. 取得程式碼

在 PowerShell 切到要放專案的資料夾，再執行：

```powershell
git clone https://github.com/Light9999x/PDF-notes.git
cd PDF-notes
```

也可在 GitHub 按「Code」→「Download ZIP」，解壓縮後於專案根目錄開啟 PowerShell。**根目錄是看得到 `app/`、`prompts/` 及 README 的位置**；已經有專案的人不必重新下載。

### 2. 安裝依賴並建置

從專案根目錄執行，初次安裝需網路：

```powershell
cd app
npm ci --cache .npm-cache
npm run build
cd ..
```

確認每一步成功後再繼續。這會產生 `app/dist/`，不會自動開啟 App。

### 3. 開啟

從專案根目錄執行：

```powershell
./app/start-pdfnote.ps1
```

保留這個終端機，自行在 Edge／Chrome 開啟 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。固定使用同一網址及瀏覽器設定檔，才能看到原有本機筆記。

### 4. 關閉

先確認「已存至本機」，關閉 App 視窗／分頁。再於另一個 PowerShell 終端機回到同一專案根目錄執行：

```powershell
./app/stop-pdfnote.ps1
```

也可在原啟動終端機按 Ctrl+C。看到「4173 無監聽」表示服務停止；已快取的 App 即使還能顯示，也不代表服務未停止。關閉視窗與停止服務是兩件事，兩者都不需要清除網站資料。

若 PowerShell 不允許執行 `.ps1`，可直接在根目錄用以下對應指令，不需變更執行原則：

```powershell
# 開啟
node ./app/scripts/preview.mjs
# 停止：在另一個終端機執行
node ./app/scripts/preview.mjs --stop
```

已經在 `app/` 時，也可用 `npm run preview` 開啟、`npm run stop` 停止。連接埠被占用時先從原工具停止占用服務，不要改用其他連接埠或一次結束所有 Node 程序。

### 5. 更新本機程式

先保存、備份並關閉 App，停止本機服務。使用 git clone 且沒有自己的程式修改時，在根目錄執行：

```powershell
git pull --ff-only
cd app
npm ci --cache .npm-cache
npm run build
cd ..
./app/start-pdfnote.ps1
```

若 Git 提示本機有修改，先處理修改再更新，不要強制覆蓋。以 ZIP 取得程式的人需下載新版並重新建置。之後開啟原網址，依 App 更新提示重新載入。

## 開發、測試與自行部署

以下指令在 `app/` 執行：

```powershell
npm run check
npm test
npm run build
node scripts/verify-build.mjs /
```

以上不啟動 App。`npm run test:e2e` 及 `npm run test:server` 會啟動服務；端到端測試設定使用 Microsoft Edge。依本專案協作偏好，代理只有在使用者明確要求時才啟動 App、服務或瀏覽器。

GitHub Actions 已設定在 main 的 App 變更時檢查並部署 `app/dist` 至 `/PDF-notes/`。自行部署至其他站點時，應依目標路徑設定 `PDFNOTE_BASE_PATH`，不能直接沿用此倉庫網址。子路徑建置與恢復本機建置步驟見 [手機測試文件](docs/MOBILE-TESTING.md)。

執行 `node scripts/release.mjs` 可將現有 `dist/` 封裝為 `release/pdfnote-0.9.0-pwa.zip`，包含依賴授權文字；先確認建置路徑與部署位置相符。ZIP 是靜態網站檔案，不是原生安裝程式。

## 支援範圍與問題回報

| 項目 | 目前狀態 |
| --- | --- |
| PDF、PNG、JPG／JPEG、`.pdfnote` | 已實作匯入；加密 PDF 需先自行解除密碼。 |
| DOC／DOCX、OCR | 尚未提供。 |
| 大小限制 | 來源檔 100 MiB、插入圖片 30 MiB、工作存檔 150 MiB；大型文件效能仍待真機測試。 |
| 文字顯示 | 使用裝置字型，跨裝置可能有字形／換行差異。 |
| 手寫筆 | 觸控筆、筆壓、防掌誤觸與真實手機多點手勢尚未驗收。 |
| 雲端與本機加密 | 尚未提供 App 端加密；刪除紀錄和歷史資產會保留以支援還原／同步。 |
| 測試狀態 | 0.9.0 的 210 項單元測試通過；本輪未啟動 App、E2E 或更新部署。建置結果及真機／同步待驗收項目見 [v009 驗證](docs/VALIDATION-V009.md)。 |
