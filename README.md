# 頁間 PDFnote

在 Windows 電腦與 Android 手機上閱讀 PDF、手寫筆記、畫重點，以及加入文字和圖片。文件先保存在自己的裝置，也可選擇連結 Google Drive 同步。

**[開啟 PDFnote](https://light9999x.github.io/PDF-notes/)** · [詳細操作與本機安裝](app/README.md) · [回報問題](https://github.com/Light9999x/PDF-notes/issues)

目前原始碼版本 **0.9.0，測試中**；本輪尚未部署到上方網站。透過瀏覽器使用，也能安裝成獨立視窗的 App（PWA）；目前沒有 APK 或 EXE 安裝檔。使用本機筆記功能不需要 Google 帳號。

## 第一次使用：照這五步開始

### 1. 開啟網站

用 Windows 的 Edge／Chrome，或 Android 的 Chrome，開啟 [PDFnote](https://light9999x.github.io/PDF-notes/)。不需要下載原始碼，也不需要讓電腦開著供手機連線。

第一次請保持連網，讓 App 下載離線需要的資源。

### 2. 安裝到裝置（可略過）

| 裝置 | 操作 |
| --- | --- |
| Windows | 在瀏覽器網址列或選單找到安裝功能，依提示安裝。 |
| Android | 在 Chrome 選單選「安裝應用程式」或「加到主畫面」，名稱依版本而異。 |

也可到 App 的「同步與設定」→「安裝與離線使用」按「安裝頁間 App」。沒有安裝按鈕時，仍可直接在瀏覽器使用。

### 3. 匯入或建立文件

- **已有文件**：按「匯入文件」，選擇 PDF、PNG、JPG／JPEG 或 `.pdfnote`。圖片會在裝置上轉成 PDF 副本，保留原圖。
- **從空白開始**：按「新建空白文件」，填名稱、選直式或橫式，再按「建立文件」。目前是 A4 白底一頁。
- **整理文件**：按「新增資料夾」，進入資料夾後再匯入或建立文件。可從文件「更多」→「移動到資料夾」調整位置；電腦也可拖曳移動。

目前不支援 Word（`.doc`／`.docx`）匯入，請先自行轉成 PDF。

### 4. 開始做筆記

開啟文件後，從上方選工具。手機工具列若顯示不全，可左右捲動。

| 想做什麼 | 怎麼操作 |
| --- | --- |
| 寫字、畫重點 | 選「畫筆」或「螢光筆」，調整顏色和直徑，再在頁面畫線。 |
| 擦掉筆跡 | 選「橡皮擦」，調整大小後按住拖曳；會刪除碰到的整筆筆跡。 |
| 輸入文字 | 選「文字」，點頁面空白位置輸入；點既有文字框可編輯。 |
| 放入圖片 | 按「插入圖片」→「選取檔案」，再拖到頁面，或點縮圖後點頁面放置。 |
| 移動、縮放、旋轉 | 選「選取」，點物件或圈選，拖物件移動、拖邊框縮放、拖圓形控制點旋轉。 |
| 閱讀與搜尋 | 用「頁面設定」選適合寬度／整頁；「搜尋」可定位並高光顯示 PDF 文字。 |

完成文字輸入、按下屬性的「套用變更」或套用去背結果後，等待顯示 **「已存至本機」** 再關閉。詳細操作見 [App 使用指南](app/README.md)。

### 5. 匯出一份備份

在文件上方按「匯出」，依用途選擇：

| 選項 | 用途 |
| --- | --- |
| **工作存檔（`.pdfnote`）** | 備份、換裝置或繼續編輯；包含原始檔、筆跡、文字、圖片及版本紀錄。 |
| **匯出 PDF** | 分享、閱讀與列印；註記合併到 PDF，不能再當成原本的獨立物件編輯。 |

`.pdfnote` 是單份文件的備份，不包含整個文件庫的資料夾分類。重新匯入同一份存檔時，App 會提供「建立副本」與「合併」，不直接覆蓋。

## 離線使用與資料保存

到「同步與設定」確認 **「App 已快取，可離線開啟」**，之後可離線閱讀、編輯及匯出。首次載入、下載更新、Google 登入及跨裝置同步需要網路。

資料保存在目前瀏覽器／裝置中。請定期匯出 `.pdfnote`，**不要用清除網站資料來關閉或更新 App**。換瀏覽器、換裝置，或從電腦本機網址改用線上網址時，需要匯入備份或設定同步，原本的本機筆記不會自動出現。

## 想在電腦和手機之間同步？

Google Drive 同步是選用功能，需要先設定自己的 Google OAuth 用戶端；目前不是登入 Google 帳號就能直接開始。

1. 依 [Google Drive 設定步驟](app/GOOGLE_DRIVE_SETUP.md) 完成設定，不需填入 client secret。
2. 在兩台裝置的「同步與設定」填入公開用戶端 ID，連結同一 Google 帳號及同一 Google Cloud 專案。
3. 保持 App 開啟，等待「同步完成」再到另一台接續操作。重新開啟或授權到期時可能需要再次連結。

兩端新增的不同物件會合併保留；同一物件有不同修改時，到「衝突管理」查看版本並選擇保留哪一版。關閉 App 後不保證持續背景同步。

## 常見問題

| 問題 | 處理方式 |
| --- | --- |
| 掃描 PDF 搜尋不到文字 | 目前沒有 OCR；搜尋需要 PDF 原本就有文字層。 |
| 不小心刪除文件 | 在「我的文件」按「已刪除文件」，找到文件後按「還原文件」。 |
| 顯示儲存失敗 | 保留目前畫面，按「重試儲存」；必要時先「匯出救援存檔」。 |
| 換了裝置，看不到筆記 | 匯入 `.pdfnote` 備份，或確認兩端已完成 Google Drive 設定與同步。 |
| 想完全在自己電腦執行 | 依 [本機建置與啟停步驟](app/README.md#在-windows-本機執行) 安裝與啟動。 |

## 目前支援與測試狀態

程式已提供 PDF／圖片匯入、資料夾、四類註記、手動圖片去背、搜尋、離線保存與兩種匯出。手動去背不是 AI 自動去背；新增註記文字匯出成 PDF 後不具有可搜尋文字層。筆記與存檔目前沒有 App 端加密。

0.9.0 已通過 210 項單元測試；本輪未啟動 App 或更新線上部署，檢查結果見 [v009 驗證紀錄](app/docs/VALIDATION-V009.md)。Windows／Galaxy S24+ 的實際安裝操作、觸控筆及真實 Google Drive 雙端同步仍待驗收。詳見 [手機測試指南](app/docs/MOBILE-TESTING.md) 與 [資安檢查報告](app/docs/SECURITY-REVIEW-0081.md)。
